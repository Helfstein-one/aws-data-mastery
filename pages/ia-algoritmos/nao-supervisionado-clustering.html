Agrupamento Baseado em Centroides

k-Means Clustering: Otimização, WCSS, Silhouette & k-means++

1.1 Introdução

O k-Means é o algoritmo de agrupamento particional mais consagrado na ciência de dados e engenharia de Machine Learning. Proposto conceitualmente por Steinhaus (1956), popularizado por MacQueen (1967) e formalizado por Lloyd (1957/1982), o k-Means visa particionar um conjunto de \(N\) observações não rotuladas em \(K\) clusters disjuntos, onde cada observação é associada ao centroide (vetor médio geometricamente representativo) de menor distância euclidiana.

1.2 Conceitos Fundamentais

O objetivo central do k-Means é minimizar a variância interna de cada agrupamento através da minimização da função custo Within-Cluster Sum of Squares (WCSS), também chamada de Inércia \(J\):

\[J(C, \boldsymbol{\mu}) = \sum_{k=1}^{K} \sum_{\mathbf{x}_i \in C_k} \|\mathbf{x}_i - \boldsymbol{\mu}_k\|^2\]

onde \(C_k\) representa o conjunto de observações pertencentes ao cluster \(k\), e \(\boldsymbol{\mu}_k \in \mathbb{R}^d\) representa o centroide (vetor médio das características) do cluster:

\[\boldsymbol{\mu}_k = \frac{1}{|C_k|} \sum_{\mathbf{x}_i \in C_k} \mathbf{x}_i\]

Algoritmo de Lloyd (Passos E & M)

1. Passo E (Expectação / Atribuição): Com centroides fixos \(\boldsymbol{\mu}^{(t)}\), atribui-se cada observação \(\mathbf{x}_i\) ao centroide mais próximo:

\[C_k^{(t)} = \left\{ \mathbf{x}_i : \|\mathbf{x}_i - \boldsymbol{\mu}_k^{(t)}\|^2 \le \|\mathbf{x}_i - \boldsymbol{\mu}_j^{(t)}\|^2 \quad \forall j \right\}\]

2. Passo M (Maximização / Atualização): Com as partições fixadas \(C^{(t)}\), atualiza-se cada centroide recalculando a média dos pontos:

\[\boldsymbol{\mu}_k^{(t+1)} = \frac{1}{|C_k^{(t)}|} \sum_{\mathbf{x}_i \in C_k^{(t)}} \mathbf{x}_i\]

Inicialização k-means++

Substitui a seleção aleatória uniforme de centroides por um amostragem probabilística proporcional à distância ao quadrado \(\text{[Arthur \& Vassilvitskii, 2007]}\):

\[P(\mathbf{x}_i) = \frac{D(\mathbf{x}_i)^2}{\sum_{j=1}^{N} D(\mathbf{x}_j)^2}\]

Garante um limite superior teórico de erro esperado \(\mathbb{E}[J] \le 8(\ln K + 2) J_{\text{opt}}\), mitigando convergência para mínimos locais ruins.

Determinação do K Ótimo

Método do Cotovelo (Elbow): Avalia o ponto de inflexão na curva \(J(K)\) onde a variação marginal \(\frac{\Delta J}{\Delta K}\) estabiliza.

Coeficiente de Silhouette \(s(i)\): Mede a coesão intra-cluster \(a(i)\) contra a separação inter-cluster \(b(i)\):

\[s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}, \quad s(i) \in [-1, +1]\]
Prova Formal: Convergência Monotônica do Algoritmo de Lloyd

O Algoritmo de Lloyd realiza minimização coordenada alternada da função custo WCSS \(J(C, \boldsymbol{\mu})\).

\[J(C^{(t+1)}, \boldsymbol{\mu}^{(t+1)}) \le J(C^{(t+1)}, \boldsymbol{\mu}^{(t)}) \le J(C^{(t)}, \boldsymbol{\mu}^{(t)})\]

No Passo E, reatribuir cada ponto ao centroide mais próximo minimiza \(J\) para centroides fixos. No Passo M, a média amostral \(\boldsymbol{\mu}_k\) é a solução exata que anula o gradiente \(\nabla_{\boldsymbol{\mu}_k} J = -2 \sum (\mathbf{x}_i - \boldsymbol{\mu}_k) = 0\). Como o número de partições de \(N\) observações em \(K\) grupos é finito (\(K^N\)) e a função custo é limitada inferiormente por zero (\(J \ge 0\)), a sequência \(J^{(t)}\) é monotonicamente não-crescente, garantindo convergência em tempo finito para um mínimo local.

1.5 Código Python Executável (scikit-learn & Strict Zero Data Leakage)

Pipeline completo scikit-learn com divisão estrita de treino/teste, ajuste do precomputador `StandardScaler` apenas no treino e avaliação multicritério:

import numpy as np
from sklearn.datasets import make_blobs
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, calinski_harabasz_score, davies_bouldin_score

# 1. Dataset Sintético de Alta Dimensionalidade (5 atributos)
X_raw, y_true = make_blobs(
    n_samples=1200,
    n_features=5,
    centers=4,
    cluster_std=1.2,
    random_state=42
)

# 2. Divisão Estrita Treino / Teste (Prevenção de Data Leakage)
X_train, X_test = train_test_split(X_raw, test_size=0.2, random_state=42)

# 3. Fit do Scaler APENAS no conjunto de Treino
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)  # Transform sem Data Leakage!

# 4. Sweep de Hiperparâmetros no Treino (Elbow & Silhouette)
wcss = []
sil_train_scores = []
k_range = range(2, 9)

for k in k_range:
    km_eval = KMeans(n_clusters=k, init='k-means++', n_init=10, max_iter=300, random_state=42)
    labels_eval = km_eval.fit_predict(X_train_scaled)
    wcss.append(km_eval.inertia_)
    sil_train_scores.append(silhouette_score(X_train_scaled, labels_eval))

# 5. Treinamento Definitivo com K=4 no Treino
optimal_k = 4
kmeans = KMeans(n_clusters=optimal_k, init='k-means++', n_init=10, max_iter=300, random_state=42)
train_labels = kmeans.fit_predict(X_train_scaled)

# 6. Inferência Out-of-Sample no Teste (Atribuição por Centroides Treinados)
test_labels = kmeans.predict(X_test_scaled)
centroids = kmeans.cluster_centers_

# 7. Avaliação Multicritério (Treino vs Teste)
sil_train = silhouette_score(X_train_scaled, train_labels)
ch_train = calinski_harabasz_score(X_train_scaled, train_labels)
db_train = davies_bouldin_score(X_train_scaled, train_labels)

sil_test = silhouette_score(X_test_scaled, test_labels)
ch_test = calinski_harabasz_score(X_test_scaled, test_labels)
db_test = davies_bouldin_score(X_test_scaled, test_labels)

print(f"=== K-MEANS CLUSTERING METRICS (K={optimal_k}) ===")
print(f"Inércia (WCSS Treino): {kmeans.inertia_:.2f}")
print(f"Silhouette Score:        Treino = {sil_train:.4f} | Teste = {sil_test:.4f} (Ideal: próximo a +1.0)")
print(f"Calinski-Harabasz Index: Treino = {ch_train:.2f} | Teste = {ch_test:.2f} (Ideal: maior valor)")
print(f"Davies-Bouldin Index:    Treino = {db_train:.4f} | Teste = {db_test:.4f} (Ideal: menor valor)")
print(f"\nCentroides Aprendidos (5D Padronizados):\n{centroids.round(3)}")

1.6 Quando Usar vs. Quando NÃO Usar

Quando USAR o k-Means
  • Clusters Convexos e Isotrópicos: Agrupamentos com geometria aproximadamente esférica e densidades similares.
  • Baixa a Média Dimensionalidade: Atributos numéricos contínuos previamente padronizados via Z-score (\(d \le 50\)).
  • Inferência em Tempo Real: Atribuição instantânea de novos pontos calculando a distância para \(K\) centroides (\(O(K \cdot d)\)).
  • Escalabilidade Big Data: Suporte nativo a agrupamento em streaming via `MiniBatchKMeans` ou PySpark MLLib em clusters AWS EMR.
Quando NÃO USAR o k-Means
  • Geometrias Não-Convexas: Clusters em formatos de luas entrelaçadas, anéis concêntricos ou espirais.
  • Presença de Outliers Extremos: A média aritmética dos centroides é altamente sensível a valores discrepantes.
  • Variâncias e Densidades Desiguais: Grupos de tamanhos ou densidades muito dispares tendem a ser particionados incorretamente.
  • Altíssima Dimensionalidade: A distância euclidiana sofre com a maldição da dimensionalidade em espaços esparsos (\(d > 500\)).

1.7 Pontos Relevantes de Engenharia & MLOps

1. Escalonamento Z-Score Obrigatório

Como o k-Means se baseia estritamente na distância euclidiana \(L_2\), variáveis com maior magnitude numérica (ex: Salário vs Idade) dominam a função custo WCSS. A aplicação do `StandardScaler` fitted no treino é pré-requisito mandatório.

2. MiniBatchKMeans para Streaming

Para datasets gigantescos que superam a RAM física, o `MiniBatchKMeans` atualiza os centroides com amostras aleatórias de tamanho fixo (\(B \approx 1024\)), reduzindo o tempo de convergência em ordens de grandeza com perda negligenciável de WCSS.

3. Atribuição Out-of-Sample em Produção

Os centroides aprendidos pelo k-Means podem ser serializados em formato PMML, ONNX ou salvos como artefato no SageMaker Model Registry, permitindo inferência online ultra-rápida via chamada ao método `.predict()`.

Agrupamento Espacial Baseado em Densidade

DBSCAN: MinPts, \(\epsilon\)-Vizinhança & Detecção Nativa de Ruído

2.1 Introdução

O DBSCAN (Density-Based Spatial Clustering of Applications with Noise), introduzido por Ester et al. (1996), é o algoritmo não-supervisionado paradigmático para a descoberta de clusters de formatos geométricos arbitrários. Diferente de algoritmos particionais como o k-Means, o DBSCAN não exige a especificação prévia do número de grupos \(K\) e identifica nativamente regiões de baixa densidade espacial como ruído ou outliers.

2.2 Conceitos Fundamentais

O comportamento do DBSCAN é governado por dois hiperparâmetros essenciais: o raio de busca espacial \(\epsilon\) (Epsilon) e a quantidade mínima de vizinhos \(\text{MinPts}\).

\(\epsilon\)-Vizinhança de um Ponto

Dada uma métrica de distância \(d(p, q)\), a \(\epsilon\)-vizinhança do ponto \(p \in \mathcal{D}\) é definida por:

\[N_\epsilon(p) = \{ q \in \mathcal{D} \mid d(p, q) \le \epsilon \}\]

Classificação Tripartida de Pontos

1. Ponto Core (Núcleo): \(|N_\epsilon(p)| \ge \text{MinPts}\)

2. Ponto Borda (Border): \(|N_\epsilon(p)| < \text{MinPts}\), porém \(p \in N_\epsilon(q)\) onde \(q\) é Core.

3. Ruído / Outlier: Não é Core nem Borda (\(\text{Label} = -1\)).

Alcançabilidade & Conectividade

Diretamente Atingível: \(p \in N_\epsilon(q)\) com \(q\) sendo um Ponto Core (relação assimétrica).

Conectado por Densidade: Existe um ancestral comum \(o\) tal que tanto \(p\) quanto \(q\) sejam atingíveis por densidade a partir de \(o\) (simétrica).

Heurística de Calibração: O Gráfico k-Distance para Seleção do Epsilon (\(\epsilon\))

Para calibrar o raio \(\epsilon\) de maneira orientada a dados, calcula-se a distância de cada ponto para o seu \(k\)-ésimo vizinho mais próximo, onde \(k = \text{MinPts} - 1\). Ordenando as distâncias em ordem decrescente, o "joelho" (ponto de máxima curvatura) no gráfico indica o limiar ótimo de \(\epsilon\). Pontos acima da inflexão pertencem a ruído esparso, enquanto pontos abaixo compõem os clusters densos.

2.3 Fórmulas KaTeX & Legenda de Símbolos

Tabela de equações estruturais do DBSCAN e legenda dos parâmetros espaciais:

Conceito Equação Formal (KaTeX) Descrição Operacional
\(\epsilon\)-Vizinhança \[N_\epsilon(p) = \{ q \in \mathcal{D} \mid d(p, q) \le \epsilon \}\] Conjunto de pontos dentro da hiperesfera de raio \(\epsilon\) centrada em \(p\).
Condição Ponto Core \[|N_\epsilon(p)| \ge \text{MinPts}\] Exigência de densidade mínima para que \(p\) seja semente de um cluster.
Rotulagem de Ruído \[\text{Label}(p) = -1 \iff |N_\epsilon(p)| < \text{MinPts} \land \nexists q \in N_\epsilon(p) \text{ core}\] Classificação automática de observações isoladas como ruído nativo.

\(\text{MinPts}\) Mínimo de Pontos Quantidade limite de vizinhos para caracterizar densidade core \(\mathbb{Z}^+\)
\(d(p, q)\) Métrica de Distância Distância euclidiana, Manhattan ou Haversine entre \(p\) e \(q\) \(\mathbb{R}_{\ge 0}\)
\(d_k(p)\) \(k\)-Distância Distância do ponto \(p\) ao seu \(k\)-ésimo vizinho mais próximo \(\mathbb{R}_{\ge 0}\)

2.5 Código Python Executável (scikit-learn com `make_moons` & Out-of-Sample Prediction)

Código reprodutível com `make_moons`, ruído uniforme, escalonamento no treino e mapeamento de inferência out-of-sample via pontos Core:

import numpy as np
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import DBSCAN
from sklearn.metrics import silhouette_score, calinski_harabasz_score, davies_bouldin_score

# 1. Dataset de Luas Entrelaçadas + Ruído Espacial Uniforme
X_moons, _ = make_moons(n_samples=850, noise=0.08, random_state=42)
np.random.seed(42)
noise_points = np.random.uniform(low=-1.5, high=2.5, size=(50, 2))
X_raw = np.vstack([X_moons, noise_points])

# 2. Divisão Estrita Treino / Teste (Prevenção de Data Leakage)
X_train, X_test = train_test_split(X_raw, test_size=0.2, random_state=42)

# 3. Escalonamento Z-score (Fit no Treino)
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# 4. Ajuste do DBSCAN no Conjunto de Treino
min_pts = 5
eps_val = 0.24
dbscan = DBSCAN(eps=eps_val, min_samples=min_pts, metric='euclidean')
train_labels = dbscan.fit_predict(X_train_scaled)

# 5. Mapeamento de Inferência Out-of-Sample para Novos Pontos (Via Distância a Core Points)
def predict_dbscan(db_model, X_tr_scaled, tr_lbls, X_te_scaled):
    core_mask = tr_lbls != -1
    if not np.any(core_mask):
        return np.full(len(X_te_scaled), -1)
    core_pts = X_tr_scaled[core_mask]
    core_lbls = tr_lbls[core_mask]
    
    # Matriz de distâncias euclidianas para os pontos Core
    dists = np.linalg.norm(X_te_scaled[:, np.newaxis, :] - core_pts[np.newaxis, :, :], axis=2)
    min_idx = np.argmin(dists, axis=1)
    min_dists = dists[np.arange(len(X_te_scaled)), min_idx]
    
    # Atribui o rótulo do Core mais próximo se dist <= eps, senão Ruído (-1)
    return np.where(min_dists <= db_model.eps, core_lbls[min_idx], -1)

test_labels = predict_dbscan(dbscan, X_train_scaled, train_labels, X_test_scaled)

# 6. Mapeamento de Métricas Filtrando Ruído (Label != -1)
train_valid = train_labels != -1
test_valid = test_labels != -1

n_clusters_train = len(set(train_labels)) - (1 if -1 in train_labels else 0)
n_noise_train = list(train_labels).count(-1)
n_noise_test = list(test_labels).count(-1)

sil_tr = silhouette_score(X_train_scaled[train_valid], train_labels[train_valid])
ch_tr = calinski_harabasz_score(X_train_scaled[train_valid], train_labels[train_valid])
db_tr = davies_bouldin_score(X_train_scaled[train_valid], train_labels[train_valid])

sil_te = silhouette_score(X_test_scaled[test_valid], test_labels[test_valid]) if np.sum(test_valid) > 2 else 0.0
ch_te = calinski_harabasz_score(X_test_scaled[test_valid], test_labels[test_valid]) if np.sum(test_valid) > 2 else 0.0
db_te = davies_bouldin_score(X_test_scaled[test_valid], test_labels[test_valid]) if np.sum(test_valid) > 2 else 0.0

print("=== DBSCAN CLUSTERING METRICS ===")
print(f"Clusters Encontrados (Treino): {n_clusters_train}")
print(f"Ruído / Outliers (Label = -1):  Treino = {n_noise_train}/{len(train_labels)} ({n_noise_train/len(train_labels):.1%}) | Teste = {n_noise_test}/{len(test_labels)} ({n_noise_test/len(test_labels):.1%})")
print(f"Silhouette Score (Sem Ruído):   Treino = {sil_tr:.4f} | Teste = {sil_te:.4f}")
print(f"Calinski-Harabasz Index:         Treino = {ch_tr:.2f} | Teste = {ch_te:.2f}")
print(f"Davies-Bouldin Index:            Treino = {db_tr:.4f} | Teste = {db_te:.4f}")

2.6 Quando Usar vs. Quando NÃO Usar

Quando USAR o DBSCAN
  • Geometrias Não-Convexas Complexas: Grupos em formato de anéis concêntricos, luas entrelaçadas ou filamentos espaciais.
  • Detecção Fina de Outliers e Fraudes: Mapeamento automático de ruídos em logs de servidores ou transações financeiras.
  • Número Desconhecido de Grupos: Quando não se possui conhecimento prévio da quantidade \(K\) de agrupamentos.
  • Dados Geográficos / GPS: Agrupamento espacial de coordenadas de latitude/longitude usando a distância Haversine.
Quando NÃO USAR o DBSCAN
  • Clusters com Densidades Muito Variadas: Um par fixo (\(\epsilon\), \(\text{MinPts}\)) não consegue separar simultaneamente regiões densas e esparsas (utilizar **HDBSCAN**).
  • Espaços de Alta Dimensão: A vizinhança hiper-esférica perde sentido geométrico devido ao esvaziamento do espaço numérico (\(d > 50\)).
  • Inferência Real-Time Sem Índice Espacial: Classificação out-of-sample sem árvore espacial (\(k\)-d tree) escala em tempo \(O(N)\) por requisição.

2.7 Pontos Relevantes de Engenharia & MLOps

1. Regra Prática para MinPts

Em engenharia de ML, adota-se a heurística \(\text{MinPts} \ge d + 1\) (onde \(d\) é a dimensionalidade). Para dados ruidosos ou 2D, a recomendação clássica é \(\text{MinPts} = 2 \cdot d\).

2. Indexação Espacial em Produção

Para otimizar as consultas de vizinhança de \(O(N^2)\) para \(O(N \log N)\), o scikit-learn utiliza algoritmos de árvore espacial (`algorithm='kd_tree'` ou `'ball_tree'`).

3. Transição para HDBSCAN

Em pipelines enterprise com variância de densidade, o HDBSCAN (Hierarchical DBSCAN) converte o raio \(\epsilon\) em um parâmetro contínuo, construindo uma árvore de hierarquia de densidade estável.

Redução de Dimensionalidade & Transformação Ortogonal

Principal Component Analysis (PCA): Matriz de Covariância, SVD & Variância Explicada

3.1 Introdução

A Análise de Componentes Principais (PCA), desenvolvida originalmente por Karl Pearson (1901) e expandida por Harold Hotelling (1933), é a técnica linear de aprendizagem não-supervisionada canônica para redução de dimensionalidade. O PCA projeta dados multivariados de alta dimensão em um novo subespaço de eixos ortogonais (Componentes Principais) alinhados com as direções de máxima variância dos dados, eliminando redundâncias e multicolinearidade sem perda significativa de informação.

3.2 Conceitos Fundamentais

Dada uma matriz de observações originais \(\mathbf{X} \in \mathbb{R}^{N \times d}\), a primeira etapa consiste na centralização dos dados subtraindo o vetor média amostral \(\boldsymbol{\mu}\):

\[\boldsymbol{\mu} = \frac{1}{N}\sum_{i=1}^{N} \mathbf{x}_i \in \mathbb{R}^d \implies \bar{\mathbf{X}} = \mathbf{X} - \mathbf{1}_N \boldsymbol{\mu}^T \in \mathbb{R}^{N \times d}\]

Calcula-se em seguida a Matriz de Covariância Amostral Simétrica \(\mathbf{\Sigma}\):

\[\mathbf{\Sigma} = \frac{1}{N-1} \bar{\mathbf{X}}^T \bar{\mathbf{X}} \in \mathbb{R}^{d \times d}\]

Decomposição Espectral (Autovalores & Autovetores)

Resolve-se a equação de autovalores para a matriz simétrica \(\mathbf{\Sigma}\):

\[\mathbf{\Sigma} \mathbf{v}_k = \lambda_k \mathbf{v}_k, \quad \text{sujeito a } \|\mathbf{v}_k\|_2 = 1, \; \mathbf{v}_i^T \mathbf{v}_j = 0 \; (i \neq j)\]

Os autovetores \(\mathbf{v}_k\) definem a direção dos eixos principais e os autovalores \(\lambda_k\) representam a variância capturada.

Decomposição em Valores Singulares (SVD)

Em produção, evita-se construir \(\mathbf{\Sigma}\) explicitamente aplicando SVD direta sobre a matriz centralizada \(\bar{\mathbf{X}}\):

\[\bar{\mathbf{X}} = \mathbf{U} \mathbf{S} \mathbf{V}^T\]

A relação algébrica exata entre os valores singulares \(s_k\) e autovalores é \(\lambda_k = \frac{s_k^2}{N-1}\).

Razão de Variância Explicada (EVR) & Corte

A taxa de variância conservada pelo \(k\)-ésimo componente é dada por:

\[\text{EVR}_k = \frac{\lambda_k}{\sum_{j=1}^{d} \lambda_j} = \frac{s_k^2}{\sum_{j=1}^{d} s_j^2}\]

Define-se o número de componentes retidos \(r\) tal que a variância acumulada \(\text{CEVR}(r) \ge 0.95\).

Prova Formal: Minimização do Erro de Reconstrução via Norma de Frobenius

Pelo Teorema de Eckart-Young-Mirsky, a projeção ortogonal \(\mathbf{Z}_r = \bar{\mathbf{X}} \mathbf{V}_r \in \mathbb{R}^{N \times r}\) sobre as \(r\) maiores colunas de \(\mathbf{V}\) produz a matriz reconstruída \(\hat{\mathbf{X}} = \mathbf{Z}_r \mathbf{V}_r^T + \mathbf{1}_N \boldsymbol{\mu}^T\) que minimiza o erro quadrático de reconstrução sob a norma de Frobenius:

\[\|\mathbf{X} - \hat{\mathbf{X}}\|_F^2 = \|\bar{\mathbf{X}} - \bar{\mathbf{X}} \mathbf{V}_r \mathbf{V}_r^T\|_F^2 = (N-1) \sum_{k=r+1}^{d} \lambda_k\]

Isso demonstra que o erro de informação descartado pela redução de dimensionalidade é exatamente proporcional à soma dos autovalores associados às componentes omitidas.

3.5 Código Python Executável (Pipeline scikit-learn & Validação SVD Manual)

Pipeline scikit-learn com `make_pipeline`, retenção de \(\ge 95\%\) da variância explicada acumulada e cálculo do erro de reconstrução MSE no conjunto de teste:

import numpy as np
from sklearn.datasets import make_blobs
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.pipeline import make_pipeline

# 1. Dataset Sintético de Alta Dimensionalidade (20 atributos)
X_raw, _ = make_blobs(n_samples=1000, n_features=20, centers=5, random_state=42)
rng = np.random.RandomState(42)
transformation_matrix = rng.randn(20, 20)
X_correlated = np.dot(X_raw, transformation_matrix)

# 2. Divisão Estrita Treino / Teste (Zero Data Leakage)
X_train, X_test = train_test_split(X_correlated, test_size=0.2, random_state=42)

# 3. Pipeline scikit-learn: Scaler + PCA conservando >= 95% da Variância
pca_pipeline = make_pipeline(
    StandardScaler(),
    PCA(n_components=0.95, svd_solver='full', random_state=42)
)

# Fit e Transform APENAS no conjunto de Treino
X_train_pca = pca_pipeline.fit_transform(X_train)

# Transform no conjunto de Teste (Zero Data Leakage)
X_test_pca = pca_pipeline.transform(X_test)

# Extração dos componentes para cálculo de métricas
scaler_step = pca_pipeline.named_steps['standardscaler']
pca_step = pca_pipeline.named_steps['pca']

# 4. Cálculo de EVR e Curva Scree Plot
evr = pca_step.explained_variance_ratio_
scree_cumsum = np.cumsum(evr)

# 5. Validação com SVD Manual no Treino (X_centered = U * S * Vt)
X_train_scaled = scaler_step.transform(X_train)
U, S, Vt = np.linalg.svd(X_train_scaled, full_matrices=False)
eigenvalues_svd = (S ** 2) / (X_train_scaled.shape[0] - 1)
evr_svd = eigenvalues_svd / np.sum(eigenvalues_svd)

# 6. Reconstrução e Erro Quadrático Médio (MSE) no Teste
X_test_scaled = scaler_step.transform(X_test)
X_test_reconstructed = pca_step.inverse_transform(X_test_pca)
test_reconstruction_mse = np.mean((X_test_scaled - X_test_reconstructed) ** 2)

print("=== PCA PIPELINE & SCREE METRICS ===")
print(f"Dimensão Original:                    {X_train.shape[1]} atributos")
print(f"Componentes Retidos (>=95% Variância): {pca_step.n_components_}")
print(f"Taxa de Compressão de Atributos:       {(1 - pca_step.n_components_ / X_train.shape[1]):.1%}")
print(f"EVR por Componente (Scikit-Learn):      {evr[:5].round(4)}")
print(f"EVR por Componente (SVD Manual):        {evr_svd[:5].round(4)}")
print(f"Scree Plot Variância Acumulada:        {scree_cumsum.round(4)}")
print(f"Erro de Reconstrução (MSE no Teste):  {test_reconstruction_mse:.6f}")

3.6 Quando Usar vs. Quando NÃO Usar

Quando USAR o PCA
  • Compressão de Vetores & Embeddings: Redução de matrizes de alta dimensão (\(d > 100\)) antes de modelos supervisionados ou Vector Search.
  • Remoção de Multicolinearidade: Converte variáveis originais correlacionadas em eixos ortogonais descorrelacionados.
  • Visualização Exploratória (2D/3D): Projeção de conjuntos de dados complexos em 2 ou 3 componentes principais.
  • Aceleração Computacional: Redução do tempo de treinamento e uso de memória de classificadores downstream.
Quando NÃO USAR o PCA
  • Estruturas e Manifolds Não-Lineares: Quando as dependências forem não-lineares, utilize t-SNE, UMAP ou Kernel PCA.
  • Requisito de Interpretabilidade Direta: Cada componente é uma combinação linear de todas as variáveis, perdendo o sentido de domínio original.
  • Matrizes Esparsas de Texto (TF-IDF): A centralização subtrai a média e destrói a esparsidade do dado (utilizar **TruncatedSVD**).

3.7 Pontos Relevantes de Engenharia & MLOps

1. Sensibilidade à Escala das Variáveis

Se as variáveis apresentarem escalas desiguais, o PCA atribuirá arbitrariamente o primeiro componente à variável de maior variância numérica. O uso do `StandardScaler` é estritamente obrigatório.

2. TruncatedSVD para TF-IDF Esparso

Em processamento de linguagem natural (NLP), o `TruncatedSVD` (LSA) executa decomposição em matrizes esparsas sem realizar a centralização de média que exigiria alocação densa de memória RAM.

3. Compressão para Vector Search (RAG)

O PCA é amplamente utilizado em sistemas RAG/GenAI para comprimir embeddings de 1536 dimensões (ex: OpenAI text-embedding-3) para 256 ou 512 dimensões, reduzindo a latência de busca em bancos vetoriais.

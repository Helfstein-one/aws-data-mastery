Agrupamento Baseado em Centroides

k-Means Clustering: Otimização, WCSS, Silhouette & k-means++

O k-Means é o algoritmo de agrupamento particional mais utilizado na indústria de dados. Seu objetivo é particionar um conjunto de \(N\) observações em \(K\) clusters distintos, onde cada observação pertence ao cluster cujo centroide (média geométrica) possui a menor distância euclidiana [MacQueen, 1967; Lloyd, 1982].

1.1 Intuição Matemática & Formulação Formal

O algoritmo de Lloyd minimiza iterativamente a soma dos quadrados das distâncias intra-cluster (conhecida como Within-Cluster Sum of Squares - WCSS ou Inércia \(J\)):

\[J = \sum_{k=1}^{K} \sum_{\mathbf{x}_i \in C_k} \| \mathbf{x}_i - \boldsymbol{\mu}_k \|^2\]

onde \(C_k\) representa o conjunto de pontos atribuídos ao cluster \(k\), e \(\boldsymbol{\mu}_k\) é o centroide (vetor médio) do cluster:

\[\boldsymbol{\mu}_k = \frac{1}{|C_k|} \sum_{\mathbf{x}_i \in C_k} \mathbf{x}_i\]

Algoritmo de Lloyd (Passo a Passo)

1. Expectação (Atribuição): Associa cada ponto ao centroide mais próximo:

\[C_k^{(t)} = \{ \mathbf{x}_i : \| \mathbf{x}_i - \boldsymbol{\mu}_k^{(t)} \|^2 \le \| \mathbf{x}_i - \boldsymbol{\mu}_j^{(t)} \|^2 \quad \forall j \}\]

2. Maximização (Atualização): Recalcula o centroide como a média dos pontos no cluster:

\[\boldsymbol{\mu}_k^{(t+1)} = \frac{1}{|C_k^{(t)}|} \sum_{\mathbf{x}_i \in C_k^{(t)}} \mathbf{x}_i\]

Inicialização k-means++

Evita convergência para mínimos locais ruins inicializando centroides espaçados proporcionalmente à distância ao quadrado [Arthur & Vassilvitskii, 2007]:

\[P(\mathbf{x}_i) = \frac{D(\mathbf{x}_i)^2}{\sum_{j=1}^{N} D(\mathbf{x}_j)^2}\]

Garante um limite logarítmico de erro \(O(\log K)\) em relação ao ótimo global.

Métrica Silhouette Score

Mede a coesão intra-cluster \(a(i)\) e separação inter-cluster \(b(i)\) para o ponto \(i\):

\[s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}, \quad s(i) \in [-1, 1]\]

Valores próximos de +1.0 indicam clusters perfeitamente bem separados.

Determinação do Número Ótimo de Clusters: Método do Cotovelo (Elbow Method) & Coeficiente de Silhouette

Como o WCSS diminui monotonicamente à medida que \(K\) aumenta (atingindo 0 quando \(K = N\)), o Método do Cotovelo busca o ponto de inflexão na curva de inércia em função de \(K\), onde a taxa de variação da inércia \(\frac{\Delta J}{\Delta K}\) se estabiliza.

Em complemento, o Silhouette Score médio avalia a qualidade do agrupamento sem necessitar de rótulos externos. O valor ótimo de \(K\) maximiza o score de Silhouette e atende aos requisitos operacionais do negócio.

1.2 Trade-offs de Produção: Quando Usar vs. Quando NÃO Usar

Quando USAR o k-Means
  • Clusters Isotrópicos e Convexos: Dados cujos agrupamentos possuem formato aproximadamente esférico e densidades homogêneas.
  • Baixa a Média Dimensionalidade: Atributos numéricos contínuos previamente escalonados (\(d \le 50\)).
  • Necessidade de Inferência em Tempo Real: Uma vez treinados os centroides, a inferência para novos pontos requer apenas o cálculo da distância euclidiana para \(K\) pontos (\(O(K \cdot d)\)).
  • Grandes Volumes de Dados: Altamente escalável via algoritmo MiniBatchKMeans ou PySpark MLLib em clusters EMR.
Quando NÃO USAR o k-Means
  • Geometrias Não-Convexas: Clusters em formatos de luas entrelaçadas, anéis concêntricos ou espirais (o k-Means falha ao assumir limites lineares).
  • Presença Significativa de Ruído / Outliers: Como os centroides são calculados pela média, um único outlier extremo desloca fortemente o centroide.
  • Densidades Desiguais: Clusters com variâncias muito distintas tendem a ser divididos incorretamente pelo algoritmo.
  • Maltdição da Dimensionalidade: Em altíssima dimensão (\(d > 500\)), a distância euclidiana perde a capacidade discriminativa (todas as distâncias tornam-se similares).

1.4 Código Python Executável (scikit-learn & MLOps Best Practices)

Abaixo apresentamos uma implementação completa com dados sintéticos (`make_blobs`), escalonamento de variáveis, sweep de hiperparâmetros (Elbow & Silhouette) e métricas formais:

import numpy as np
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, calinski_harabasz_score, davies_bouldin_score

# 1. Gerar Dataset Sintético com 4 clusters bem definidos em 5 dimensões
X_raw, y_true = make_blobs(
    n_samples=1200,
    n_features=5,
    centers=4,
    cluster_std=1.2,
    random_state=42
)

# 2. MLOps Best Practice: Padronização Z-score (Essencial para Distância Euclidiana)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_raw)

# 3. Avaliação de Hiperparâmetros (Sweep K=2 até K=8)
wcss = []
silhouette_coefficients = []
k_range = range(2, 9)

for k in k_range:
    kmeans_eval = KMeans(n_clusters=k, init='k-means++', n_init=10, max_iter=300, random_state=42)
    kmeans_eval.fit(X_scaled)
    wcss.append(kmeans_eval.inertia_)
    score = silhouette_score(X_scaled, kmeans_eval.labels_)
    silhouette_coefficients.append(score)

# 4. Treinamento do Modelo Definitivo com K=4 (k-means++)
optimal_k = 4
kmeans_final = KMeans(
    n_clusters=optimal_k,
    init='k-means++',
    n_init=10,
    max_iter=300,
    random_state=42
)
cluster_labels = kmeans_final.fit_predict(X_scaled)
centroids = kmeans_final.cluster_centers_

# 5. Avaliação Multicritério do Agrupamento
sil_avg = silhouette_score(X_scaled, cluster_labels)
ch_score = calinski_harabasz_score(X_scaled, cluster_labels)
db_score = davies_bouldin_score(X_scaled, cluster_labels)

print(f"=== K-MEANS CLUSTERING METRICS (K={optimal_k}) ===")
print(f"Inertia (WCSS): {kmeans_final.inertia_:.2f}")
print(f"Silhouette Score: {sil_avg:.4f} (Ideal: próximo de +1.0)")
print(f"Calinski-Harabasz Index: {ch_score:.2f} (Ideal: maior valor)")
print(f"Davies-Bouldin Index: {db_score:.4f} (Ideal: menor valor)")
print(f"Centroides (5D Padronizados):\n{centroids.round(3)}")

Agrupamento Espacial Baseado em Densidade

DBSCAN: MinPts, \(\epsilon\)-Vizinhança & Detecção Nativa de Ruído

O DBSCAN (Density-Based Spatial Clustering of Applications with Noise) conecta regiões contínuas de alta densidade de pontos separadas por regiões de baixa densidade. Ao contrário do k-Means, o DBSCAN não exige a definição prévia do número de clusters \(K\) e é capaz de identificar clusters de formatos geométricos arbitrários, isolando nativamente ruídos e outliers [Ester et al., 1996].

2.1 Intuição Matemática & Classificação de Pontos

O algoritmo é governado por dois hiperparâmetros fundamentais: a distância máxima \(\epsilon\) (Epsilon) e o número mínimo de pontos \(\text{MinPts}\).

\(\epsilon\)-Vizinhança de um Ponto

O conjunto de pontos dentro do raio \(\epsilon\) em relação a \(p\):

\[N_\epsilon(p) = \{ q \in D \mid \text{dist}(p, q) \le \epsilon \}\]

Classificação Estrutural de Pontos

1. Ponto Core (Núcleo): \(|N_\epsilon(p)| \ge \text{MinPts}\)

2. Ponto Borda (Border): \(|N_\epsilon(p)| < \text{MinPts}\), mas pertence à vizinhança de um Ponto Core.

3. Ruído / Outlier: Não é Core nem Borda (\(\text{Rótulo} = -1\)).

Alcançabilidade & Conectividade

Diretamente Atingível por Densidade: \(p \in N_\epsilon(q)\) com \(q\) sendo um Ponto Core.

Conectado por Densidade: Existe uma cadeia de pontos conectando \(p\) e \(q\) a um ancestral Core comum \(o\).

Heurística de Calibração: O Gráfico k-Distance para Seleção do Epsilon (\(\epsilon\))

Para calibrar \(\epsilon\), calcula-se a distância de cada observação para seu \(k\)-ésimo vizinho mais próximo, onde \(k = \text{MinPts} - 1\). Ordenando essas distâncias em ordem crescente e plotando a curva resultante, o ponto de inflexão ("joelho" ou cotovelo) indica o valor ótimo de \(\epsilon\).

2.2 Trade-offs de Produção: Quando Usar vs. Quando NÃO Usar

Quando USAR o DBSCAN
  • Formatos Geométricos Complexos: Clusters não-esféricos, em forma de U, espirais, filamentos ou superfícies não-lineares.
  • Detecção Fina de Outliers / Fraudes: Identificação automática de dados ruidosos sem contaminar o agrupamento dos dados válidos.
  • Número de Clusters Desconhecido: Quando não há conhecimento a priori da quantidade \(K\) de grupos na base.
  • Dados Espaciais e Geoespaciais: Agrupamento de coordenadas GPS (Latitude, Longitude) via métrica Haversine.
Quando NÃO USAR o DBSCAN
  • Clusters com Densidades Variadas: Um único par (\(\epsilon\), \text{MinPts}) não consegue capturar simultaneamente regiões muito densas e regiões esparsas (para isso, utilize HDBSCAN).
  • Altíssima Dimensionalidade: Devido à maldição da dimensionalidade, em espaços de alta dimensão o conceito de vizinhança esférica se esvazia.
  • Alta Complexidade de Inferência: Atribuir novos pontos em tempo real exige comparar contra toda a base treinada (\(O(N)\) sem árvore espacial).

2.4 Código Python Executável (scikit-learn com `make_moons`)

Abaixo demonstramos a aplicação do DBSCAN em dados não-convexos com inclusão deliberada de ruído sintético:

import numpy as np
from sklearn.datasets import make_moons
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import DBSCAN
from sklearn.neighbors import NearestNeighbors
from sklearn.metrics import silhouette_score

# 1. Gerar Dataset de Luas Entrelaçadas + Ruído Uniforme
X_moons, _ = make_moons(n_samples=850, noise=0.08, random_state=42)

np.random.seed(42)
noise_points = np.random.uniform(low=-1.5, high=2.5, size=(50, 2))
X_raw = np.vstack([X_moons, noise_points])

# 2. MLOps Best Practice: Escalonamento Z-score
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_raw)

# 3. Heurística k-distance para estimar Epsilon (k = MinPts - 1)
min_pts = 5
neighbors = NearestNeighbors(n_neighbors=min_pts)
neighbors_fit = neighbors.fit(X_scaled)
distances, indices = neighbors_fit.kneighbors(X_scaled)
sorted_k_distances = np.sort(distances[:, min_pts - 1])

# 4. Ajuste do Modelo DBSCAN com Epsilon Otimizado
dbscan = DBSCAN(eps=0.22, min_samples=min_pts, metric='euclidean')
labels = dbscan.fit_predict(X_scaled)

# 5. Avaliação do Agrupamento e Filtragem de Outliers
core_samples_mask = np.zeros_like(labels, dtype=bool)
core_samples_mask[dbscan.core_sample_indices_] = True

n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
n_noise = list(labels).count(-1)

non_noise_mask = labels != -1
sil_score = silhouette_score(X_scaled[non_noise_mask], labels[non_noise_mask]) if n_clusters > 1 else 0.0

print(f"=== DBSCAN CLUSTERING METRICS ===")
print(f"Clusters Encontrados: {n_clusters}")
print(f"Pontos de Ruído / Outliers (Label = -1): {n_noise} ({n_noise/len(labels):.1%})")
print(f"Pontos Núcleo (Core Points): {np.sum(core_samples_mask)}")
print(f"Silhouette Score (Somente Clusters Válidos): {sil_score:.4f}")

Redução de Dimensionalidade & Transformação Ortogonal

Principal Component Analysis (PCA): Matriz de Covariância, SVD & Variância Explicada

A Análise de Componentes Principais (PCA) é a técnica não-supervisionada canônica para redução de dimensionalidade linear. O PCA projeta os dados originais em um novo sistema de coordenadas ortogonais de menor dimensão, maximizando a variância retida ou minimizando o erro quadrático médio de reconstrução [Pearson, 1901; Jolliffe, 2002].

3.1 Intuição Matemática, Matriz de Covariância & SVD

Dada uma matriz de dados \(\mathbf{X} \in \mathbb{R}^{N \times d}\), a primeira etapa consiste na centralização dos dados na média:

\[\mathbf{X}_{\text{centered}} = \mathbf{X} - \mathbf{1} \boldsymbol{\mu}^T, \quad \text{onde } \boldsymbol{\mu} = \frac{1}{N}\sum_{i=1}^{N} \mathbf{x}_i\]

Em seguida, calcula-se a Matriz de Covariância Amostral \(\mathbf{\Sigma}\):

\[\mathbf{\Sigma} = \frac{1}{N-1} \mathbf{X}_{\text{centered}}^T \mathbf{X}_{\text{centered}} \in \mathbb{R}^{d \times d}\]

Equação de Autovalores & Autovetores

Os autovetores \(\mathbf{v}_i\) determinam as direções dos componentes principais e os autovalores \(\lambda_i\) medem a variância:

\[\mathbf{\Sigma} \mathbf{v}_i = \lambda_i \mathbf{v}_i, \quad \text{com } \|\mathbf{v}_i\| = 1\]

Decomposição em Valores Singulares (SVD)

Em vez de \(\mathbf{\Sigma}\), aplica-se SVD diretamente sobre a matriz centralizada [Golub & Reinsch, 1970]:

\[\mathbf{X}_{\text{centered}} = \mathbf{U} \mathbf{S} \mathbf{V}^T\]

Onde \(\lambda_i = \frac{\sigma_i^2}{N-1}\), garantindo maior estabilidade numérica.

Razão de Variância Explicada (EVR)

A proporção de variância retida pelo \(i\)-ésimo componente principal é dada por:

\[\text{EVR}_i = \frac{\lambda_i}{\sum_{j=1}^{d} \lambda_j}, \quad \text{Variância Acumulada}(k) = \frac{\sum_{i=1}^{k} \lambda_i}{\sum_{j=1}^{d} \lambda_j}\]
Projeção Ortogonal & Reconstrução com Erro Mínimo

Selecionando os \(k\) maiores autovetores \(\mathbf{W}_k = [\mathbf{v}_1, \mathbf{v}_2, \dots, \mathbf{v}_k] \in \mathbb{R}^{d \times k}\), a projeção reduzida é obtida por:

\[\mathbf{Z} = \mathbf{X}_{\text{centered}} \mathbf{W}_k \in \mathbb{R}^{N \times k}\]

A reconstrução aproximada \(\hat{\mathbf{X}} = \mathbf{Z} \mathbf{W}_k^T + \mathbf{1}\boldsymbol{\mu}^T\) minimiza o Erro Quadrático Médio (MSE) de reconstrução para qualquer subespaço linear de dimensão \(k\).

3.2 Trade-offs de Produção: Quando Usar vs. Quando NÃO Usar

Quando USAR o PCA
  • Compressão de Embeddings e Altíssima Dimensionalidade: Redução de vetores de features (\(d > 100\)) antes de aplicar classificadores ou agrupamentos.
  • Eliminação de Multicolinearidade: Transforma atributos altamente correlacionados em componentes ortogonais (não-correlacionados).
  • Visualização de Dados (2D/3D): Projeção em 2 ou 3 componentes principais para análise exploratória.
  • Aceleração de Pipelines de ML: Reduz drasticamente a memória e o tempo de treinamento de modelos subsequentes.
Quando NÃO USAR o PCA
  • Manifolds Não-Lineares: Se as relações entre os dados forem não-lineares (ex: Swiss Roll), utilize técnicas como t-SNE, UMAP ou Kernel PCA.
  • Necessidade de Interpretabilidade Direta: Cada componente principal é uma combinação linear de todas as variáveis originais, perdendo o significado direto do domínio.
  • Matrizes Esparsas Gigantes: A centralização da média remove a esparsidade do dado (para matrizes esparsas como TF-IDF, utilize TruncatedSVD).

3.4 Código Python Executável (NumPy SVD vs. scikit-learn PCA)

Abaixo apresentamos a validação da equivalência matemática entre a decomposição SVD manual e a biblioteca `sklearn.decomposition.PCA`:

import numpy as np
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# 1. Gerar Dataset Sintético de Alta Dimensionalidade (20 características)
X_raw, _ = make_blobs(n_samples=1000, n_features=20, centers=5, random_state=42)

# Adicionar correlação linear sintética entre atributos
transformation_matrix = np.random.RandomState(42).randn(20, 20)
X_correlated = np.dot(X_raw, transformation_matrix)

# 2. MLOps Best Practice: Centralizar Média e Padronizar Variância (Z-Score)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_correlated)

# 3. Implementação Manual do PCA via Decomposição SVD (X = U * S * Vt)
U, S, Vt = np.linalg.svd(X_scaled, full_matrices=False)
eigenvalues_svd = (S ** 2) / (X_scaled.shape[0] - 1)
evr_svd = eigenvalues_svd / np.sum(eigenvalues_svd)

# 4. Scikit-Learn PCA Conservando 95% da Variância Explicada Acumulada
pca = PCA(n_components=0.95, svd_solver='full', random_state=42)
X_pca = pca.fit_transform(X_scaled)

# 5. Métricas de Compressão e Reconstrução da Matriz
n_components_retained = pca.n_components_
explained_variance = pca.explained_variance_ratio_
cumulative_variance = np.cumsum(explained_variance)

# Reconstrução da matriz original a partir do subespaço reduzido
X_reconstructed = pca.inverse_transform(X_pca)
reconstruction_mse = np.mean((X_scaled - X_reconstructed) ** 2)

print(f"=== PCA DIMENSIONALITY REDUCTION METRICS ===")
print(f"Dimensão Original: {X_scaled.shape[1]} atributos")
print(f"Componentes Retidos (>=95% Variância): {n_components_retained}")
print(f"Taxa de Compressão de Atributos: {(1 - n_components_retained / X_scaled.shape[1]):.1%}")
print(f"EVR por Componente (Scikit-Learn): {explained_variance[:5].round(4)}")
print(f"EVR por Componente (SVD Manual):   {evr_svd[:5].round(4)}")
print(f"Variância Acumulada Retida: {cumulative_variance[-1]:.4f}")
print(f"Erro Quadrático Médio (MSE) de Reconstrução: {reconstruction_mse:.6f}")

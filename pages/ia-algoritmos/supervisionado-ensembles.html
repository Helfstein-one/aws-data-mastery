Bagging, Subamostragem & Estimativa OOB

Random Forest (Florestas Aleatórias)

1.1 Introdução & Visão Geral

O algoritmo Random Forest (Breiman, 2001) é um método de aprendizado ensemble baseado no agrupamento de árvores de decisão fracamente correlacionadas. Ele combina duas técnicas de amostragem estocástica: Bagging (Bootstrap Aggregating) para amostragem de observações com reposição e o Método do Subespaço Aleatório (Random Subspace Method) para amostragem de atributos. Essa dupla aleatorização reduz drasticamente a variância do modelo final sem aumentar significativamente o viés individual dos estimadores.

1.2 Conceitos Fundamentais & Intuição

Considere um conjunto de treinamento \(D = \{(x_1, y_1), (x_2, y_2), \dots, (x_N, y_N)\}\) com \(p\) atributos independentes. O Random Forest constrói um conjunto de \(B\) árvores de decisão independentes \(\{T_1(x), T_2(x), \dots, T_B(x)\}\). Para cada árvore \(b \in \{1, \dots, B\}\), extrai-se uma amostra bootstrap \(D_b^*\) contendo \(N\) observações sorteadas com reposição a partir de \(D\).

Redução de Variância por Bagging

Seja \(\bar{X} = \frac{1}{B}\sum_{b=1}^B T_b(x)\) a média de \(B\) árvores idênticamente distribuídas, cada uma com variância \(\sigma^2\) e correlação par a par \(\rho\). A variância do ensemble é expressa por:

\[\text{Var}(\bar{X}) = \rho \sigma^2 + \frac{1-\rho}{B}\sigma^2\]

Conforme o número de árvores \(B \to \infty\), o segundo termo aproxima-se de zero, restando o piso teórico \(\rho \sigma^2\). A subamostragem de atributos diminui a correlação \(\rho\), reduzindo a variância global.

Subamostragem de Atributos (Random Subspace)

Em cada nó de divisão de cada árvore, seleciona-se aleatoriamente um subconjunto de \(m\) variáveis dentre as \(p\) totais:

\[m \approx \sqrt{p} \quad (\text{Classificação}) \qquad \text{ou} \qquad m \approx \frac{p}{3} \quad (\text{Regressão})\]

Garante que atributos fortemente preditivos não dominem a raiz de todas as árvores, forçando a diversidade estrutural da floresta.

1.3 Fórmulas KaTeX & Tabela de Glossário de Símbolos

Demonstração Matemática do Limite Out-Of-Bag (OOB ~ 36.8%)

Em uma amostragem bootstrap com reposição de tamanho \(N\), a probabilidade de uma observação específica não ser selecionada em um único sorteio é \(1 - \frac{1}{N}\). A probabilidade de ela ficar fora da amostra bootstrap em todos os \(N\) sorteios independentes é \(\left(1 - \frac{1}{N}\right)^N\).

Tomando o limite quando o número de amostras \(N \to \infty\):

\[L = \lim_{N \to \infty} \left(1 - \frac{1}{N}\right)^N\]

Aplicando o logaritmo natural em ambos os lados e utilizando a expansão em série de Taylor \(\ln(1 - x) = -x - \frac{x^2}{2} - \frac{x^3}{3} - \dots\) para \(x = \frac{1}{N}\):

\[\ln L = \lim_{N \to \infty} N \ln\left(1 - \frac{1}{N}\right) = \lim_{N \to \infty} N \left( -\frac{1}{N} - \frac{1}{2N^2} - \frac{1}{3N^3} - \dots \right) = \lim_{N \to \infty} \left( -1 - \frac{1}{2N} - \dots \right) = -1\]

Aplicando a função exponencial:

\[L = e^{-1} = \frac{1}{e} \approx 0.367879 \quad (\approx 36.8\%)\]

Conclui-se que cada amostra bootstrap contém aproximadamente \(1 - 1/e \approx 63.2\%\) de dados únicos, deixando \(36.8\%\) das observações como conjunto de validação Out-Of-Bag (OOB).

Formulação da Importância de Atributos (MDI & MDA)

1. Mean Decrease Impurity (MDI / Gini Importance): SOMA ponderada da redução de impureza em todos os nós onde o atributo \(X_j\) é utilizado para divisão:

\[\text{MDI}(X_j) = \frac{1}{B} \sum_{b=1}^B \sum_{t \in T_b : v(t) = j} p(t) \Delta i(t)\]

onde \(p(t) = \frac{N_t}{N}\) é a proporção de amostras no nó \(t\) e \(\Delta i(t) = i(t) - \frac{N_{t_L}}{N_t} i(t_L) - \frac{N_{t_R}}{N_t} i(t_R)\) com impureza de Gini \(G(S) = 1 - \sum p_k^2\).

2. Mean Decrease Accuracy (MDA / Permutation Importance): Medida sobre as amostras OOB permutando aleatoriamente o atributo \(X_j\):

\[\text{MDA}(X_j) = \frac{1}{B} \sum_{b=1}^B \frac{1}{|D_b^{\text{OOB}}|} \sum_{i \in D_b^{\text{OOB}}} \left[ L\left(y_i, \, T_b(x_{i, \pi(j)})\right) - L\left(y_i, \, T_b(x_i)\right) \right]\]

1.5 Arquitetura MLOps AWS & Código Python Executável

Abaixo apresenta-se a arquitetura MLOps de produção na AWS para treinamento distribuído e servimento de Random Forest, seguida do pipeline executável em Python sem vazamento de dados:

Fluxo MLOps AWS: Dados brutos processados no EMR Serverless são persistidos na camada Silver S3 Iceberg, catalogados no SageMaker Feature Store e servidos em jobs de treinamento. O artefato serializado é publicado via SageMaker Endpoint. 
import numpy as np
import pandas as pd
import joblib
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import (
    accuracy_score, precision_score, recall_score, f1_score,
    roc_auc_score, log_loss
)

# 1. Reprodutibilidade e Semente Aleatória
SEED = 42
np.random.seed(SEED)

# 2. Geração de Dataset Sintético de Risco de Crédito
X_raw, y_raw = make_classification(
    n_samples=10000,
    n_features=15,
    n_informative=10,
    n_redundant=3,
    n_clusters_per_class=2,
    weights=[0.8, 0.2],
    random_state=SEED
)

feature_names = [f"feature_{i:02d}" for i in range(15)]
df_features = pd.DataFrame(X_raw, columns=feature_names)

# 3. Divisão de Treino e Teste (Stratified Split)
X_train_raw, X_test_raw, y_train, y_test = train_test_split(
    df_features, y_raw, test_size=0.20, stratify=y_raw, random_state=SEED
)

# 4. Prevenção Rígida de Data Leakage: StandardScaler (Fit apenas no Treino)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train_raw)
X_test = scaler.transform(X_test_raw)  # APENAS transform no conjunto de teste!

# 5. Instanciação e Otimização via GridSearch com OOB Score
rf_base = RandomForestClassifier(
    oob_score=True,
    random_state=SEED,
    n_jobs=-1
)

param_grid = {
    'n_estimators': [100, 200],
    'max_depth': [10, 15],
    'max_features': ['sqrt', 'log2'],
    'min_samples_split': [2, 5]
}

grid_search = GridSearchCV(
    estimator=rf_base,
    param_grid=param_grid,
    cv=5,
    scoring='roc_auc',
    n_jobs=-1
)

print("Iniciando treinamento do Random Forest...")
grid_search.fit(X_train, y_train)
best_rf = grid_search.best_estimator_

# 6. Predições e Métricas Completas no Teste
y_pred = best_rf.predict(X_test)
y_prob = best_rf.predict_proba(X_test)[:, 1]

metrics = {
    "Accuracy": accuracy_score(y_test, y_pred),
    "Precision": precision_score(y_test, y_pred),
    "Recall": recall_score(y_test, y_pred),
    "F1-Score": f1_score(y_test, y_pred),
    "AUC-ROC": roc_auc_score(y_test, y_prob),
    "Log-Loss": log_loss(y_test, y_prob),
    "OOB-Score (Treino)": best_rf.oob_score_
}

print("\n--- MÉTRICAS DE AVALIAÇÃO DO RANDOM FOREST ---")
for k, v in metrics.items():
    print(f"{k:20s}: {v:.4f}")

# 7. Serialização MLOps com joblib
joblib.dump(best_rf, "random_forest_model.joblib")
joblib.dump(scaler, "scaler_rf.joblib")
print("\n[MLOps] Modelo e Scaler serializados com sucesso (.joblib).")

1.6 Quando Usar vs Quando NÃO Usar (Trade-offs)

✅ Quando Usar (Vantagens)

  • Baseline Robustíssimo: Alta performance "out-of-the-box" sem necessidade de tuning complexo.
  • Resistência a Overfitting: O aumento de árvores \(B\) reduz a variância sem degradar o viés.
  • Validação Gratuita via OOB: A estimativa OOB (~36.8%) substitui a necessidade de conjunto de validação separado.
  • Totalmente Paralelizável: Árvores independentes aceleram o treino em clusters multi-core CPU.

❌ Quando NÃO Usar (Desvantagens)

  • Sem Extrapolação em Regressão: Incapaz de prever valores fora do intervalo min/max observado no treino.
  • Latência e Memória Elevadas: Centenas de árvores profundas exigem grande pegada de memória e aumentam latência de inferência (\(>10\text{ ms}\)).
  • Dados Esparsos / Alta Dimensão: Inferior ao SVM ou modelos lineares em matrizes esparsas de texto (TF-IDF).

1.7 Pontos Relevantes & Boas Práticas de Engenharia

  • Controle de Profundidade: Fixe `max_depth` entre 10 e 20 em datasets massivos para conter o crescimento exponencial de memória RAM do modelo.
  • Monitoramento de Impureza vs Permutação: A importância por Gini (MDI) tende a inflacionar atributos numéricos continuos de alta cardinalidade; prefira Permutation Importance (MDA) para decisões finais de Feature Selection.
  • Serialização Eficiente: Ao salvar com `joblib`, utilize o nível de compressão `compress=3` para reduzir o tamanho dos arquivos `.joblib` em até 70%.

Gradient Boosting (GBM)

2.1 Introdução & Visão Geral

O Gradient Boosting (Friedman, 2001) é um algoritmo ensemble seqüencial onde cada nova árvore de decisão é adicionada para corrigir os erros (resíduos) cometidos pelo conjunto de árvores anteriores. Ele interpreta o aprendizado como uma otimização por descida de gradiente em espaço funcional, permitindo otimizar qualquer função de perda diferenciável.

2.2 Conceitos Fundamentais & Intuição

Dado um dataset \(D = \{(x_i, y_i)\}_{i=1}^N\) e uma função de perda diferenciável \(L(y, f(x))\), busca-se uma função \(f^*(x)\) que minimize o risco empírico:

\[f^* = \arg\min_f \sum_{i=1}^N L(y_i, f(x_i))\]

O algoritmo constrói a solução de forma aditiva \(f_M(x) = f_0(x) + \sum_{m=1}^M \nu h_m(x)\), onde \(f_0(x)\) é uma constante inicial, \(h_m(x)\) são estimadores fracos (árvores de decisão rasas) e \(\nu\) é a taxa de aprendizado (Shrinkage).

2.3 Fórmulas KaTeX & Tabela de Glossário de Símbolos

Derivação em Espaço Funcional & Expansão de Taylor de 1ª Ordem

No espaço de funções \(N\)-dimensional avaliado nos pontos de treino \(\mathbf{f} = (f(x_1), \dots, f(x_N))^T\), o gradiente negativo determina a direção de maior declive para redução de perda:

\[g_{im} = -\left[ \frac{\partial L(y_i, f(x_i))}{\partial f(x_i)} \right]_{f(x_i) = f_{m-1}(x_i)}\]

Aplicando a expansão de Taylor de 1ª ordem sobre a função de perda ao adicionar um pequeno passo \(h(x_i)\):

\[L(y_i, f_{m-1}(x_i) + h(x_i)) \approx L(y_i, f_{m-1}(x_i)) + \left[ \frac{\partial L(y_i, f(x_i))}{\partial f(x_i)} \right]_{f=f_{m-1}} h(x_i) = L(y_i, f_{m-1}(x_i)) - r_{im} h(x_i)\]

Para maximizar a redução da perda, ajusta-se a árvore fraca \(h_m(x)\) aos pseudo-resíduos \(r_{im}\) minimizando o erro quadrático:

\[\theta_m = \arg\min_{\theta} \sum_{i=1}^N \left( r_{im} - h(x_i; \theta) \right)^2\]

Dedução Explícita dos Resíduos para Funções de Perda

1. Perda Quadrática (MSE para Regressão): \(L(y, f) = \frac{1}{2}(y - f)^2\)

\[r_{im} = -\frac{\partial}{\partial f} \left[ \frac{1}{2}(y_i - f)^2 \right] = y_i - f_{m-1}(x_i)\]

2. Perda Logística (Binary Log-Loss): \(L(y, f) = \log(1 + e^{-y f})\) onde \(y \in \{-1, +1\}\)

\[r_{im} = -\frac{\partial}{\partial f} \log(1 + e^{-y_i f}) = \frac{y_i e^{-y_i f_{m-1}(x_i)}}{1 + e^{-y_i f_{m-1}(x_i)}} = \frac{y_i}{1 + e^{y_i f_{m-1}(x_i)}}\]

Glossário de Símbolos — Gradient Boosting

Símbolo Nome / Significado Descrição & Papel Matemático
\(f_m(x)\) Modelo Acumulado na Iteração \(m\) Soma aditiva das estimativas constantes e árvores anteriores.
\(r_{im}\) Pseudo-Resíduo da Observação \(i\) Gradiente negativo da função de perda avaliado na iteração anterior.
\(h_m(x)\) Árvore Fraca Ajustada aos Resíduos Estimador fraco treinado via mínimos quadrados nos pseudo-resíduos.
\(\nu\) Taxa de Aprendizado (Shrinkage) Fator de ponderação \(0 < \nu \le 1\) para desacelerar o aprendizado e conter overfitting.

import numpy as np
import pandas as pd
import joblib
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import (
    accuracy_score, precision_score, recall_score, f1_score,
    roc_auc_score, log_loss
)

# 1. Semente Aleatória
SEED = 42
np.random.seed(SEED)

# 2. Dataset Sintético de Sinistro de Seguros
X_raw, y_raw = make_classification(
    n_samples=8000,
    n_features=12,
    n_informative=8,
    n_redundant=2,
    weights=[0.85, 0.15],
    random_state=SEED
)

# 3. Divisão Treino e Teste
X_train_raw, X_test_raw, y_train, y_test = train_test_split(
    X_raw, y_raw, test_size=0.25, stratify=y_raw, random_state=SEED
)

# 4. Zero Data Leakage: Fit do Scaler estritamente no Treino
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train_raw)
X_test = scaler.transform(X_test_raw)

# 5. Modelo Gradient Boosting com Shrinkage
gbm = GradientBoostingClassifier(
    n_estimators=150,
    learning_rate=0.05,
    max_depth=4,
    subsample=0.8,
    min_samples_split=10,
    random_state=SEED
)

print("Treinando GradientBoostingClassifier...")
gbm.fit(X_train, y_train)

# 6. Avaliação Estagiada (Staged Loss)
staged_losses = [log_loss(y_test, y_pred_staged) for y_pred_staged in gbm.staged_predict_proba(X_test)]
best_iter = np.argmin(staged_losses) + 1

# 7. Métricas de Avaliação
y_pred = gbm.predict(X_test)
y_prob = gbm.predict_proba(X_test)[:, 1]

metrics = {
    "Accuracy": accuracy_score(y_test, y_pred),
    "Precision": precision_score(y_test, y_pred),
    "Recall": recall_score(y_test, y_pred),
    "F1-Score": f1_score(y_test, y_pred),
    "AUC-ROC": roc_auc_score(y_test, y_prob),
    "Log-Loss": log_loss(y_test, y_prob),
    "Melhor Iteração Staged": best_iter
}

print("\n--- MÉTRICAS DE AVALIAÇÃO DO GRADIENT BOOSTING ---")
for k, v in metrics.items():
    print(f"{k:22s}: {v:.4f}" if isinstance(v, float) else f"{k:22s}: {v}")

# 8. Salvamento de Artefatos
joblib.dump(gbm, "gradient_boosting_model.joblib")
joblib.dump(scaler, "scaler_gbm.joblib")
print("\n[MLOps] Modelo e Scaler serializados com sucesso.")

2.6 Quando Usar vs Quando NÃO Usar (Trade-offs)

✅ Quando Usar (Vantagens)

  • Acurácia Competitiva Excepcional: Freqüentemente supera a Random Forest em dados tabulares complexos.
  • Otimização de Perdas Customizadas: Funciona com qualquer função de perda diferenciável (Huber, Log-Loss, Quantile Loss).
  • Eficiência com Árvores Rasas: Excelente capacidade preditiva utilizando árvores rasas (\(\text{max\_depth} \in [3, 6]\)).

❌ Quando NÃO Usar (Desvantagens)

  • Treino Seqüencial Mais Lento: A iteração \(m\) depende obrigatoriamente dos resíduos do modelo \(m-1\).
  • Sensibilidade a Ruídos e Outliers: Pode superajustar a dados ruidosos se o valor de \(\nu\) for muito elevado.

2.7 Pontos Relevantes & Boas Práticas de Engenharia

  • Regra Prática de Shrinkage: Reduza a taxa de aprendizado \(\nu\) para valores entre \(0.01\) e \(0.05\) e aumente o número de árvores \(M\) proporcionalmente para obter melhor generalização.
  • Subamostragem Estocástica (Subsample): Utilize `subsample=0.8` em cada iteração para simular bagging e prevenir a memorização de dados ruidosos.

Expansão de Taylor de 2ª Ordem & Regularização L1/L2

XGBoost (Extreme Gradient Boosting)

3.1 Introdução & Visão Geral

O XGBoost (Chen & Guestrin, 2016) é uma implementação escalável e de altíssimo desempenho do Gradient Boosting. Suas inovações fundamentais incluem a aproximação da função de perda por expansão de Taylor de 2ª ordem, inclusão explícita de termos de regularização \(L_1\) e \(L_2\) na função objetivo, construção otimizada de árvores baseada em histogramas e suporte nativo a execução paralela em GPU.

3.2 Conceitos Fundamentais & Intuição

Na iteração \(t\), a função objetivo a ser minimizada para a predição \(\hat{y}_i^{(t)} = \hat{y}_i^{(t-1)} + f_t(x_i)\) é composta pela perda empírica mais a penalidade estrutural da árvore \(\Omega(f_t)\):

\[\mathcal{L}^{(t)} = \sum_{i=1}^N L\left(y_i, \, \hat{y}_i^{(t-1)} + f_t(x_i)\right) + \Omega(f_t)\]

onde o termo de regularização da árvore com \(T\) folhas e vetor de pesos \(w\) é dado por:

\[\Omega(f_t) = \gamma T + \frac{1}{2} \lambda \sum_{j=1}^T w_j^2 + \alpha \sum_{j=1}^T |w_j|\]

3.3 Fórmulas KaTeX & Tabela de Glossário de Símbolos

Derivação da Expansão de Taylor de 2ª Ordem & Pesos Folha Ótimos (\(w_j^*\))

Expandindo a perda \(L(y_i, \hat{y}_i^{(t-1)} + f_t(x_i))\) em série de Taylor de 2ª ordem em torno da predição anterior \(\hat{y}_i^{(t-1)}\):

\[\mathcal{L}^{(t)} \approx \sum_{i=1}^N \left[ L(y_i, \hat{y}_i^{(t-1)}) + g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i) \right] + \Omega(f_t)\]

onde os gradientes de 1ª ordem (\(g_i\)) e Hessianos de 2ª ordem (\(h_i\)) são calculados por:

\[g_i = \frac{\partial L(y_i, \hat{y}_i^{(t-1)})}{\partial \hat{y}_i^{(t-1)}} \qquad \text{e} \qquad h_i = \frac{\partial^2 L(y_i, \hat{y}_i^{(t-1)})}{\partial (\hat{y}_i^{(t-1)})^2}\]

Removendo os termos constantes independentes de \(f_t\) e reordenando a soma pelo conjunto de instâncias que caem na folha \(j\), dado por \(I_j = \{i : x_i \in R_j\}\):

\[\tilde{\mathcal{L}}^{(t)} = \sum_{j=1}^T \left[ \left(\sum_{i \in I_j} g_i\right) w_j + \frac{1}{2} \left(\sum_{i \in I_j} h_i + \lambda\right) w_j^2 \right] + \gamma T = \sum_{j=1}^T \left[ G_j w_j + \frac{1}{2}(H_j + \lambda) w_j^2 \right] + \gamma T\]

Derivando \(\tilde{\mathcal{L}}^{(t)}\) em relação ao peso folha \(w_j\) e igualando a zero para encontrar a condição de ótimo:

\[\frac{\partial \tilde{\mathcal{L}}^{(t)}}{\partial w_j} = G_j + (H_j + \lambda) w_j = 0 \implies w_j^* = -\frac{G_j}{H_j + \lambda} = -\frac{\sum_{i \in I_j} g_i}{\sum_{i \in I_j} h_i + \lambda}\]

Score Estrutural Mínimo & Ganho de Divisão (\(\mathcal{L}_{split}\))

Substituindo o peso ótimo \(w_j^*\) de volta na função objetivo obtém-se a Pontuação de Qualidade Estrutural do nó:

\[\tilde{\mathcal{L}}^{(t)}(w^*) = -\frac{1}{2} \sum_{j=1}^T \frac{G_j^2}{H_j + \lambda} + \gamma T\]

O Ganho de Divisão ao dividir um nó em filho esquerdo (\(L\)) e direito (\(R\)) representa a redução da perda regulada por \(\gamma\):

\[\text{Gain} = \frac{1}{2} \left[ \frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda} \right] - \gamma\]

Glossário de Símbolos — XGBoost

Símbolo Nome / Significado Descrição & Papel Matemático
\(g_i, h_i\) Gradiente (1ª Ordem) e Hessiano (2ª Ordem) Derivadas primeira e segunda da perda em relação à predição anterior.
\(w_j^*\) Peso Ótimo da Folha \(j\) Valor terminal calculado em função dos gradientes e hessianos acumulados na folha.
\(\lambda, \alpha\) Penalidades de Regularização \(L_2\) e \(L_1\) Parâmetros de encolhimento de pesos para evitar sobre-ajuste dos nós.
\(\gamma\) Custo Mínimo de Ganho por Folha Threshold de ganho necessário para autorizar a criação de um novo nó filho.

import pandas as pd
import joblib
import xgboost as xgb
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split

from sklearn.metrics import (

  • Padrão Ouro para Dados Tabulares: Desempenho estado da arte em dados estruturados corporativos.

  • Parâmetro `scale_pos_weight`: Em problemas desbalanceados (ex: fraude com 5% de positivos), defina `scale_pos_weight = total_neg / total_pos` para equilibrar a contribuição dos gradientes.
  • Early Stopping com Evaluation Set: Passe um conjunto de validação estritamente separado para interromper o treinamento caso a perda estagne por mais de `early_stopping_rounds=20` iterações.

Maximização de Margem, Dualidade & Truque do Kernel

Support Vector Machine (SVM)

4.1 Introdução & Visão Geral

O Support Vector Machine (SVM) (Cortes & Vapnik, 1995) é um modelo supervisionado fundamentado na Teoria de Aprendizado Estatístico (Vapnik-Chervonenkis). Ele busca determinar o hiperplano ótimo de separação que maximiza a margem geométrica entre as classes. Por meio da formulação dual de Lagrange e do Truque do Kernel (Kernel Trick), o SVM projeta os dados para espaços de dimensão arbitrária (até infinita) sem explicitar as transformações dos vetores.

4.2 Conceitos Fundamentais & Intuição

Dado um dataset separável ou parcialmente separável \(D = \{(x_i, y_i)\}_{i=1}^N\) com \(y_i \in \{-1, +1\}\), a busca pelo hiperplano \(w^T x + b = 0\) de margem máxima é traduzida no problema primal de Margem Suave (Soft Margin) com variáveis de folga \(\xi_i \ge 0\):

\[\min_{w, b, \xi} \, \frac{1}{2} \|w\|^2 + C \sum_{i=1}^N \xi_i \qquad \text{sujeito a} \qquad y_i (w^T x_i + b) \ge 1 - \xi_i, \quad \xi_i \ge 0\]

4.3 Fórmulas KaTeX & Tabela de Glossário de Símbolos

Derivação do Problema Dual via Lagrangiano

Construindo a função Lagrangiana do problema primal com multiplicadores \(\alpha_i \ge 0\) e \(\mu_i \ge 0\):

\[\mathcal{L}(w, b, \xi, \alpha, \mu) = \frac{1}{2} \|w\|^2 + C \sum_{i=1}^N \xi_i - \sum_{i=1}^N \alpha_i \left[ y_i (w^T x_i + b) - 1 + \xi_i \right] - \sum_{i=1}^N \mu_i \xi_i\]

Calculando as derivadas parciais e impondo a condição de estacionaridade de 1ª ordem (\(\nabla \mathcal{L} = 0\)):

  1. \(\frac{\partial \mathcal{L}}{\partial w} = 0 \implies w = \sum_{i=1}^N \alpha_i y_i x_i\)
  2. \(\frac{\partial \mathcal{L}}{\partial b} = 0 \implies \sum_{i=1}^N \alpha_i y_i = 0\)
  3. \(\frac{\partial \mathcal{L}}{\partial \xi_i} = 0 \implies C - \alpha_i - \mu_i = 0 \implies 0 \le \alpha_i \le C \quad (\text{dado } \mu_i \ge 0)\)

Substituindo essas relações de volta na função Lagrangiana, obtém-se o Problema Dual de Programação Quadrática (QP):

\[\max_{\alpha} \, \sum_{i=1}^N \alpha_i - \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y_i y_j K(x_i, x_j) \qquad \text{sujeito a} \qquad 0 \le \alpha_i \le C, \quad \sum_{i=1}^N \alpha_i y_i = 0\]

Tabela de Condições de Otimidade Karush-Kuhn-Tucker (KKT)

Condição KKT Formulação Matemática Significado Físico / Geométrico
Estacionaridade \(w = \sum \alpha_i y_i x_i, \quad \sum \alpha_i y_i = 0\) O vetor normal \(w\) é combinação linear dos vetores de suporte.
Viabilidade Primal \(y_i(w^T x_i + b) \ge 1 - \xi_i, \quad \xi_i \ge 0\) Todas as amostras respeitam as margens com folga \(\xi_i\).
Viabilidade Dual \(0 \le \alpha_i \le C, \quad \mu_i \ge 0\) Multiplicadores restritos pela penalidade \(C\).
Folga Complementar \(\alpha_i [y_i(w^T x_i + b) - 1 + \xi_i] = 0\) Apenas pontos sobre ou violando a margem possuem \(\alpha_i > 0\).

Interpretação dos Regimes de \(\alpha_i\) & Teorema de Mercer

  • \(\alpha_i = 0 \implies \xi_i = 0\): Ponto classificado corretamente fora da margem. Não afeta a fronteira.
  • \(0 < \alpha_i < C \implies \xi_i = 0\): Vetor de Suporte posicionado exatamente sobre a margem (\(y_i(w^T x_i + b) = 1\)).
  • \(\alpha_i = C \implies \xi_i \ge 0\): Vetor de Suporte dentro da margem ou mal classificado.

Teorema de Mercer: Uma função simétrica \(K(x, z)\) é um Kernel válido se e somente se para qualquer função \(g(x)\) de quadrado integrável, tem-se \(\iint K(x, z) g(x) g(z) dx dz \ge 0\) (a matriz de Gram é semi-definida positiva).

Formulário de Kernels principais:

  • Linear: \(K(x_i, x_j) = x_i^T x_j\)
  • Polinomial: \(K(x_i, x_j) = (\gamma x_i^T x_j + r)^d\)
  • RBF (Gaussiano): \(K(x_i, x_j) = \exp(-\gamma \|x_i - x_j\|^2)\)
  • Sigmoide: \(K(x_i, x_j) = \tanh(\gamma x_i^T x_j + r)\)

Glossário de Símbolos — SVM

Símbolo Nome / Significado Descrição & Papel Matemático
\(w, b\) Vetor de Pesos e Viés (Bias) Parâmetros ortogonais que definem a orientação e deslocamento do hiperplano.
\(\xi_i\) Variáveis de Folga (Slack Variables) Mede a distância de violação da margem para a observação \(i\).
\(C\) Parâmetro de Regularização Soft-Margin Trade-off entre maximizar a margem (\(\|w\|\)) e minimizar violações (\(\sum \xi_i\)).
\(\alpha_i\) Multiplicador de Lagrange Dual Ponderação da observação na solução dual. Pontos com \(\alpha_i > 0\) são Vetores de Suporte.

4.5 Arquitetura MLOps AWS & Código Python Executável

Abaixo ilustra-se a arquitetura de inferência serverless em tempo real na AWS e o script Python contendo padronização `StandardScaler` e `SVC` otimizado via `GridSearchCV`:

Pipeline Serverless SVM: Os vetores padronizados no Feature Store alimentam o modelo com Kernel RBF. O Endpoint do SageMaker executa Platt Scaling para responder requisições HTTPS via API Gateway + Lambda. 
import numpy as np
import pandas as pd
import joblib
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.metrics import (
    accuracy_score, precision_score, recall_score, f1_score,
    roc_auc_score, log_loss
)

# 1. Controle de Semente
SEED = 42
np.random.seed(SEED)

# 2. Dataset Sintético em Alta Dimensão (2.000 amostras, 50 atributos)
X_raw, y_raw = make_classification(
    n_samples=2000,
    n_features=50,
    n_informative=35,
    n_redundant=10,
    random_state=SEED
)

# 3. Divisão de Treino e Teste
X_train_raw, X_test_raw, y_train, y_test = train_test_split(
    X_raw, y_raw, test_size=0.25, stratify=y_raw, random_state=SEED
)

# 4. Zero Data Leakage: Fit do Scaler EXCLUSIVAMENTE em X_train_raw
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train_raw)
X_test = scaler.transform(X_test_raw)

# 5. Otimização de Hiperparâmetros via GridSearch
svc = SVC(probability=True, random_state=SEED)
param_grid = {
    'C': [0.1, 1.0, 10.0],
    'gamma': ['scale', 'auto'],
    'kernel': ['rbf', 'linear']
}

grid_svm = GridSearchCV(
    estimator=svc,
    param_grid=param_grid,
    cv=5,
    scoring='roc_auc',
    n_jobs=-1
)

print("Treinando e otimizando SVM com StandardScaler...")
grid_svm.fit(X_train, y_train)
best_svm = grid_svm.best_estimator_

# 6. Métricas de Avaliação e Extração de Vetores de Suporte
y_pred = best_svm.predict(X_test)
y_prob = best_svm.predict_proba(X_test)[:, 1]

metrics = {
    "Accuracy": accuracy_score(y_test, y_pred),
    "Precision": precision_score(y_test, y_pred),
    "Recall": recall_score(y_test, y_pred),
    "F1-Score": f1_score(y_test, y_pred),
    "AUC-ROC": roc_auc_score(y_test, y_prob),
    "Log-Loss": log_loss(y_test, y_prob),
    "Nº Vetores de Suporte": len(best_svm.support_)
}

print("\n--- MÉTRICAS DE AVALIAÇÃO DO SVM ---")
for k, v in metrics.items():
    print(f"{k:24s}: {v:.4f}" if isinstance(v, float) else f"{k:24s}: {v}")

# 7. Salvamento MLOps com joblib
joblib.dump(best_svm, "svm_model.joblib")
joblib.dump(scaler, "scaler_svm.joblib")
print("\n[MLOps] Modelo SVM e Scaler serializados com sucesso.")

4.6 Quando Usar vs Quando NÃO Usar (Trade-offs)

✅ Quando Usar (Vantagens)

  • Alta Dimensão (\(p \gg N\)): Eficácia excelente onde o número de atributos supera o de amostras (ex: TF-IDF, genômica).
  • Margens Matemáticas Robustas: A maximização da margem geométrica diminui riscos de sobre-ajuste em amostras pequenas.
  • Eficiência de Memória de Inferência: O modelo depende exclusivamente do subconjunto dos Vetores de Suporte.

❌ Quando NÃO Usar (Desvantagens)

  • Inviável em Big Data (\(N > 100.000\)): Resolução de Programação Quadrática varia entre \(O(N^2)\) e \(O(N^3)\).
  • Sensibilidade Crítica a Escalas: Exige padronização Z-score rígida de todos os atributos.
  • Calibração de Probabilidades Externa: Exige calibração por validação cruzada (Platt Scaling) para gerar probabilidades.

4.7 Pontos Relevantes & Boas Práticas de Engenharia

  • Padronização Obrigatória: Sempre encadeie `StandardScaler` e `SVC` dentro de pipelines para garantir que dados de teste/validação não sofram vazamento durante o ajuste do z-score.
  • Kernel Linear vs RBF: Em problemas de NLP onde \(p > 10.000\), prefira o Kernel Linear (`kernel='linear'`), que possui complexidade computacional muito menor mantendo alta acurácia.

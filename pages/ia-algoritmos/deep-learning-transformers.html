Artificial Neural Network (ANN) & Multilayer Perceptron (MLP)

1.1 Introdução

A Rede Neural Artificial (ANN) na forma de Multilayer Perceptron (MLP) é a estrutura fundamental do aprendizado profundo. Composta por uma camada de entrada, uma ou mais camadas ocultas e uma camada de saída, a MLP aprende aproximações de funções não-lineares complexas através da combinação de transformações afins e funções de ativação [Goodfellow et al., 2016].

1.2 Conceitos Fundamentais

Dado um vetor de entrada \(x \in \mathbb{R}^{d_{in}}\), a propagação direta (Forward Propagation) em uma camada \(l\) é definida por uma combinação linear ponderada seguida por uma transformação não-linear:

\[z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}\] \[a^{(l)} = \sigma(z^{(l)})\]

Onde \(W^{(l)} \in \mathbb{R}^{n_l \times n_{l-1}}\) representa a matriz de pesos, \(b^{(l)} \in \mathbb{R}^{n_l}\) é o vetor de viés (bias), e \(\sigma(\cdot)\) é a função de ativação. Para a camada inicial, \(a^{(0)} = x\), e para a camada final de saída \(L\), \(a^{(L)} = \hat{y}\).

Funções de Ativação & Prova Formal do Backpropagation

Funções de Ativação Fundamentais:

  • Sigmoid: \(\sigma(z) = \frac{1}{1 + e^{-z}}\). Comprime valores no intervalo \((0, 1)\), com derivada \(\sigma'(z) = \sigma(z)(1 - \sigma(z))\).
  • ReLU (Rectified Linear Unit): \(f(z) = \max(0, z)\). Eficiente computacionalmente com derivada \(f'(z) = 1\) para \(z > 0\).
  • GELU (Gaussian Error Linear Unit): \(f(z) = z \cdot \Phi(z) = z \cdot \frac{1}{2} \left[1 + \text{erf}\left(\frac{z}{\sqrt{2}}\right)\right]\). Padrão em redes modernas (BERT, GPT, LLaMA).
  • Softmax: \(p_i = \frac{e^{z_i}}{\sum_{j=1}^C e^{z_j}}\). Converte logits \(z\) em uma distribuição multinomial de probabilidade.

Prova Formal: Regra da Cadeia no Backpropagation

Seja \(L\) a função de perda. Define-se o sinal de erro da camada \(l\) como \(\delta^{(l)} = \frac{\partial L}{\partial z^{(l)}}\). Pela regra da cadeia:

\[\delta^{(L)} = \nabla_{a^{(L)}} L \odot \sigma'(z^{(L)})\] \[\delta^{(l)} = \left( (W^{(l+1)})^T \delta^{(l+1)} \right) \odot \sigma'(z^{(l)})\] \[\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^T, \quad \frac{\partial L}{\partial b^{(l)}} = \delta^{(l)}\]

Conceito Equação Formal (KaTeX) Descrição Operacional

Binary Cross-Entropy (BCE) \[L_{\text{BCE}} = -\frac{1}{N}\sum_{i=1}^{N} [y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i)]\] Perda para classificação binária baseada na divergência KL.

Otimizador AdamW \[\theta_{t+1} = \theta_t - \eta \left( \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon} + \lambda \theta_t \right)\] Momento adaptativo de 1ª/2ª ordem com decaimento de peso desacoplado.

1.5 Código Executável em PyTorch (MLP com AdamW)

import torch
import torch.nn as nn
import torch.optim as optim

# Boas práticas de MLOps: Fixação de seed e configuração de dispositivo hardware
torch.manual_seed(42)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Definição da Arquitetura Multilayer Perceptron (MLP) com GELU e BatchNorm
class MultilayerPerceptron(nn.Module):
    def __init__(self, input_dim: int, hidden_dim: int, output_dim: int, dropout_prob: float = 0.1):
        super(MultilayerPerceptron, self).__init__()
        self.layer1 = nn.Linear(input_dim, hidden_dim)
        self.bn1 = nn.BatchNorm1d(hidden_dim)
        self.act1 = nn.GELU()
        self.dropout = nn.Dropout(dropout_prob)
        self.layer2 = nn.Linear(hidden_dim, output_dim)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        out = self.layer1(x)
        out = self.bn1(out)
        out = self.act1(out)
        out = self.dropout(out)
        logits = self.layer2(out)
        return logits

# Instanciação do modelo e envio para a GPU/CPU
input_size, hidden_size, num_classes = 64, 128, 1
model = MultilayerPerceptron(input_size, hidden_size, num_classes).to(device)

# Sintetização de batch de tensores tabulares (Batch Size = 32)
X_synthetic = torch.randn(32, input_size, device=device)
y_synthetic = torch.randint(0, 2, (32, 1), dtype=torch.float32, device=device)

# Função de Perda (BCE com Logits) e Otimizador AdamW
criterion = nn.BCEWithLogitsLoss()
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)

# Passagem Direta (Forward)
logits = model(X_synthetic)
loss = criterion(logits, y_synthetic)

# Passagem Reversa (Backpropagation)
optimizer.zero_grad()
loss.backward()
optimizer.step()

print(f"Perda ANN/MLP calculada com sucesso: {loss.item():.4f}")

1.6 Quando Usar vs Não Usar

Quando Usar ANN / MLP
  • Dados tabulares de alta dimensão com interações não-lineares complexas.
  • Camadas finais de classificação/regressão no topo de representações latentes.
  • Aplicações com latência estrita de inferência (sub-5ms) onde GPU/CPU reduzidas são suficientes.
  • Mapeamento direto de atributos estruturados extraídos via Feature Store.
Quando NÃO Usar ANN / MLP
  • Dados de imagens/vídeos brutos (alta redundância espacial — utilize CNNs).
  • Sequências textuais ou temporais com dependências de longo alcance (utilize Transformers).
  • Datasets tabulares pequenos/médios onde modelos Tree-Based (XGBoost, LightGBM) superam MLPs.
  • Cenários onde explicabilidade direta de coeficientes seja pré-requisito regulatório estrito.

Convolutional Neural Network (CNN)

2.1 Introdução

As Redes Neurais Convolucionais (CNNs) revolucionaram o processamento de sinais e imagens ao substituir multiplicações matriciais densas por operações de convolução local. Baseadas no princípio da invariância por translação e compartilhamento de pesos, as CNNs extraem hierarquias visuais desde bordas simples até padrões semânticos complexos [LeCun et al., 1998].

2.2 Conceitos Fundamentais

A operação de Convolução 2D sobre uma imagem ou mapa de características de entrada \(I\) com um kernel/filtro \(K\) de tamanho \(k_h \times k_w\) é definida por:

\[(I * K)(i, j) = \sum_{m=0}^{k_h-1} \sum_{n=0}^{k_w-1} I(i + m, j + n) \cdot K(m, n)\]

Dada uma entrada de dimensão \((H_{in}, W_{in})\), com padding \(P\), stride \(S\) e kernel de tamanho \(K\), as dimensões espaciais do mapa de características de saída (Feature Map) são calculadas por:

\[H_{out} = \left\lfloor \frac{H_{in} + 2P - K}{S} \right\rfloor + 1, \quad W_{out} = \left\lfloor \frac{W_{in} + 2P - K}{S} \right\rfloor + 1\]
Campo Receptivo & Prova da Conexão Residual ResNet

Campo Receptivo (Receptive Field): Expande-se recursivamente com a profundidade da rede:

\[RF_l = RF_{l-1} + (K_l - 1) \cdot \prod_{i=1}^{l-1} S_i\]

Pooling (Agrupamento Espacial): Max Pooling seleto o valor máximo; Global Average Pooling (GAP) reduz \((B, C, H, W)\) para \((B, C, 1, 1)\).

Prova Formal: Fluxo Desimpedido de Gradientes na ResNet

Seja o bloco residual \(y = \mathcal{F}(x, \{W_i\}) + x\). Durante o backpropagation, o gradiente da perda \(L\) em relação à entrada \(x\) é dado por:

\[\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \frac{\partial y}{\partial x} = \frac{\partial L}{\partial y} \left( \frac{\partial \mathcal{F}}{\partial x} + 1 \right)\]

Mesmo se o gradiente da transformação \(\frac{\partial \mathcal{F}}{\partial x}\) se aproxime de zero, o termo adicional \(+1\) garante que o gradiente \(\frac{\partial L}{\partial y}\) flua diretamente para camadas anteriores sem desvanecimento!

2.3 Fórmulas KaTeX & Legenda de Símbolos

A tabela abaixo descreve as equações fundamentais do processamento convolucional 2D:

Conceito Equação Formal (KaTeX) Descrição Operacional
Convolução 2D Discreta \[Z(i,j) = \sum_{m} \sum_{n} X(i+m, j+n) K(m,n)\] Soma ponderada do produto elemento a elemento entre imagem e kernel.
Dimensão de Saída Spatial \[H_{out} = \left\lfloor \frac{H + 2P - K}{S} \right\rfloor + 1\] Cálculo do tamanho do Feature Map resultante considerando Stride e Padding.
Campo Receptivo Acumulado \[RF_l = RF_{l-1} + (K_l - 1) \prod_{i=1}^{l-1} S_i\] Área total da imagem de entrada vista por um neurônio da camada \(l\).
Bloco Residual ResNet \[y = \mathcal{F}(x, \{W_i\}) + x\] Atalho aditivo que viabiliza o treinamento de redes com 150+ camadas.

2.5 Código Executável em PyTorch (Bloco Residual ResNet)

import torch
import torch.nn as nn
import torch.optim as optim

# Configuração MLOps
torch.manual_seed(42)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Implementação de Bloco Residual (ResNet) com Convoluções 2D e Skip Connection
class ResidualConvBlock(nn.Module):
    def __init__(self, in_channels: int, out_channels: int, stride: int = 1):
        super(ResidualConvBlock, self).__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, kernel_size=3, stride=stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU(inplace=True)
        self.conv2 = nn.Conv2d(out_channels, out_channels, kernel_size=3, stride=1, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        
        # Conexão de atalho para ajuste de dimensões se houver alteração de stride/canais
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, kernel_size=1, stride=stride, bias=False),
                nn.BatchNorm2d(out_channels)
            )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        identity = self.shortcut(x)
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += identity # Conexão aditiva residual
        return self.relu(out)

# Classificador CNN completo com Global Average Pooling
class ResNetClassifier(nn.Module):
    def __init__(self, num_classes: int = 10):
        super(ResNetClassifier, self).__init__()
        self.stem = nn.Sequential(
            nn.Conv2d(3, 32, kernel_size=3, stride=1, padding=1, bias=False),
            nn.BatchNorm2d(32),
            nn.ReLU(inplace=True)
        )
        self.res_block1 = ResidualConvBlock(32, 64, stride=2)
        self.gap = nn.AdaptiveAvgPool2d((1, 1))
        self.fc = nn.Linear(64, num_classes)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        out = self.stem(x)
        out = self.res_block1(out)
        out = self.gap(out)
        out = torch.flatten(out, 1)
        return self.fc(out)

# Modelo e dados sintéticos (Batch=8, Canais=3, H=64, W=64)
model_cnn = ResNetClassifier(num_classes=10).to(device)
images = torch.randn(8, 3, 64, 64, device=device)
labels = torch.randint(0, 10, (8,), device=device)

# Loss & Otimizador AdamW
criterion_cnn = nn.CrossEntropyLoss()
optimizer_cnn = optim.AdamW(model_cnn.parameters(), lr=1e-3, weight_decay=1e-4)

# Passagem direta e backward pass
outputs = model_cnn(images)
loss_cnn = criterion_cnn(outputs, labels)

optimizer_cnn.zero_grad()
loss_cnn.backward()
optimizer_cnn.step()

print(f"Perda CNN ResNet calculada com sucesso: {loss_cnn.item():.4f}")

Transformer Architecture & Aplicações em LLMs / GenAI

3.1 Introdução

A arquitetura Transformer é o pilar fundamental dos Large Language Models (LLMs) modernos e da IA Generativa. Ao abandonar a recorrência sequencial das RNNs em favor do mecanismo de Self-Attention (Auto-Atenção), o Transformer viabiliza o processamento massivamente paralelo de sequências longas e a captura de contextos globais [Vaswani et al., 2017].

3.2 Conceitos Fundamentais

Dado um conjunto de embeddings de entrada \(X \in \mathbb{R}^{N \times d_{model}}\), calculam-se as matrizes de Query (\(Q\)), Key (\(K\)) e Value (\(V\)) através de projeções lineares aprendidas:

\[Q = X W_Q, \quad K = X W_K, \quad V = X W_V\]

A equação da Scaled Dot-Product Attention realiza a pontuação de relevância semântica entre pares de tokens:

\[\text{Attention}(Q, K, V) = \text{softmax}\left( \frac{Q K^T}{\sqrt{d_k}} \right) V\]
Prova Matemática do Fator de Escala \(\sqrt{d_k}\) & Multi-Head Attention

Prova da Variância do Produto Escalar:

Assuma que os componentes dos vetores \(q, k \in \mathbb{R}^{d_k}\) sejam variáveis aleatórias independentes com média 0 e variância 1: \(\mathbb{E}[q_i] = \mathbb{E}[k_i] = 0\) e \(\text{Var}(q_i) = \text{Var}(k_i) = 1\). O produto escalar é \(q \cdot k = \sum_{i=1}^{d_k} q_i k_i\).

A média do produto é \(\mathbb{E}[q_i k_i] = \mathbb{E}[q_i] \mathbb{E}[k_i] = 0\). A variância de cada termo é:

\[\text{Var}(q_i k_i) = \mathbb{E}[q_i^2 k_i^2] - (\mathbb{E}[q_i k_i])^2 = \mathbb{E}[q_i^2] \mathbb{E}[k_i^2] - 0 = 1 \times 1 = 1\]

Como os termos são independentes, a variância da soma é a soma das variâncias:

\[\text{Var}(q \cdot k) = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = d_k\]

Portanto, o desvio padrão do produto escalar é \(\sqrt{d_k}\). Ao dividir por \(\sqrt{d_k}\), a variância de \(\frac{q \cdot k}{\sqrt{d_k}}\) é reescalada para exatos 1, prevenindo que a função Softmax sature em regiões com gradientes nulos!

Multi-Head Attention (MHA): Concatenam-se \(h\) cabeças de atenção independentes para capturar subespaços de representação simultâneos:

\[\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O\]

Variantes de Arquitetura: Encoder-Decoder, Encoder-Only e Decoder-Only

Encoder-Only (BERT)

Atenção bidirecional completa em toda a sequência. Ideal para classificação de texto, Extração de Entidades (NER) e geração de embeddings densos de busca semântica.

Encoder-Decoder (T5, BART)

Encoder bidirecional combinado a um Decoder causal autoregressivo. Otimizado para tradução de idiomas, sumarização abstrativa e tarefas sequence-to-sequence.

Decoder-Only (GPT-4, Claude, LLaMA)

Atenção causal mascarada (cada token só enxerga os anteriores). Arquitetura padrão da indústria para Modelos de Linguagem de Grande Porte (LLMs) e IA Generativa.

Conceito Equação Formal (KaTeX) Descrição Operacional
Projeções Lineares Q, K, V \[Q = X W_Q, \quad K = X W_K, \quad V = X W_V\] Mapeamento das entradas para subespaços de Query, Key e Value.

3.5 Código Executável em PyTorch & HuggingFace (Self-Attention & LLM Pipeline)

import math
import torch
import torch.nn as nn
import torch.nn.functional as F

# MLOps Setup
torch.manual_seed(42)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Módulo de Auto-Atenção Dimensionado (Scaled Dot-Product Self-Attention)
class ScaledDotProductSelfAttention(nn.Module):
    def __init__(self, d_model: int, n_heads: int):
        super(ScaledDotProductSelfAttention, self).__init__()
        self.d_model = d_model
        self.n_heads = n_heads
        self.head_dim = d_model // n_heads
        assert self.head_dim * n_heads == d_model, "d_model precisa ser divisível por n_heads"
        
        self.q_proj = nn.Linear(d_model, d_model)
        self.k_proj = nn.Linear(d_model, d_model)
        self.v_proj = nn.Linear(d_model, d_model)
        self.out_proj = nn.Linear(d_model, d_model)

    def forward(self, x: torch.Tensor, mask: torch.Tensor = None) -> torch.Tensor:
        batch_size, seq_len, _ = x.size()
        
        # Projeção linear Q, K, V e separação em múltiplas cabeças (Multi-Head)
        Q = self.q_proj(x).view(batch_size, seq_len, self.n_heads, self.head_dim).transpose(1, 2)
        K = self.k_proj(x).view(batch_size, seq_len, self.n_heads, self.head_dim).transpose(1, 2)
        V = self.v_proj(x).view(batch_size, seq_len, self.n_heads, self.head_dim).transpose(1, 2)
        
        # Scaled Dot-Product Attention: (Q * K^T) / sqrt(d_k)
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.head_dim)
        
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
            
        attn_weights = F.softmax(scores, dim=-1)
        context = torch.matmul(attn_weights, V)
        
        # Reagrupamento das cabeças de atenção e projeção final
        context = context.transpose(1, 2).contiguous().view(batch_size, seq_len, self.d_model)
        return self.out_proj(context)

# Instanciação do mecanismo de atenção (Batch=4, SeqLen=16, d_model=128, n_heads=4)
attn_module = ScaledDotProductSelfAttention(d_model=128, n_heads=4).to(device)
tokens_synthetic = torch.randn(4, 16, 128, device=device)

attn_output = attn_module(tokens_synthetic)
print(f"Formato do Tensor de Saída da Atenção: {attn_output.shape}")

3.6 Quando Usar vs Não Usar

Quando Usar Transformers
  • Processamento de Linguagem Natural avançado, geração de texto e código.
  • Sistemas RAG (Retrieval-Augmented Generation) e Agentes Autônomos.
  • Processamento Multimodal unificado (Texto + Imagem + Áudio).
  • Captura de relações contextuais em sequências extensas (128k+ tokens).
Quando NÃO Usar Transformers
  • Hardware com restrição extrema de VRAM e SLA microsecondário (< 1ms).
  • Datasets tabulares pequenos onde a complexidade quadrática \(\mathcal{O}(N^2)\) não compensa o custo.
  • Aplicações sem infraestrutura distribuída para gerenciamento de KV-Cache na AWS.

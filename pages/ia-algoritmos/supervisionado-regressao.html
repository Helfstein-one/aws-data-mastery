Seção 1: Regressão Linear (Linear Regression)

Modelagem paramétrica contínua baseada na minimização dos resíduos quadráticos, soluções analíticas fechadas vs numéricas iterativas e estabilização de coeficientes via regularização L1/L2.

1.1 Intuição Matemática e Hipótese de Linearidade

A Regressão Linear assume uma relação linear entre o vetor de atributos preditores \(\mathbf{x} = [x_1, x_2, \dots, x_p]^T \in \mathbb{R}^p\) e a variável resposta contínua \(y \in \mathbb{R}\). Formalmente, a hipótese do modelo é expressa por:

\[ y = h_\beta(\mathbf{x}) + \varepsilonarepsilon = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_p x_p + \varepsilonarepsilon = \mathbf{x}^T \beta + \varepsilonarepsilon \]

Onde \(\mathbf{x} = [1, x_1, x_2, \dots, x_p]^T\) inclui o termo de ajuste (bias/intercepto), \(\beta = [\beta_0, \beta_1, \dots, \beta_p]^T \in \mathbb{R}^{p+1}\) é o vetor de parâmetros a ser estimado, e \(\varepsilonarepsilon\) representa o termo de erro estocástico irredutível.

Pressupostos Estatísticos do Modelo Linear Clássico (Gauss-Markov):
  • Linearidade nos Parâmetros: A esperança condicional da variável resposta é linear nos coeficientes \(\beta\): \(E[y|\mathbf{X}] = \mathbf{X}\beta\).
  • Exogeneidade Estrita: O valor esperado do termo de erro condicional aos atributos é zero: \(E[\varepsilonarepsilon|\mathbf{X}] = 0\).
  • Homocedasticidade: A variância do erro é constante para todas as observações: \( ext{Var}(\varepsilonarepsilon_i|\mathbf{X}) = \sigma^2, \forall i\).
  • Ausência de Autocorrelação: Os erros de observações distintas são não correlacionados: \( ext{Cov}(\varepsilonarepsilon_i, \varepsilonarepsilon_j|\mathbf{X}) = 0, \forall i eq j\).
  • Ausência de Multicolinearidade Perfeita: A matriz de atributos \(\mathbf{X} \in \mathbb{R}^{n imes (p+1)}\) possui posto pleno de coluna (\( ext{rank}(\mathbf{X}) = p + 1 \le n\)).

1.2 Função de Custo OLS (Ordinary Least Squares)

A estimativa dos parâmetros \(\beta\) via Mínimos Quadrados Ordinários (OLS) busca minimizar a soma dos quadrados dos resíduos (Residual Sum of Squares - RSS) entre os valores reais \(y^{(i)}\) e as predições \(\hat{y}^{(i)} = h_\beta(\mathbf{x}^{(i)})\). A função de custo de erro médio quadrático (Mean Squared Error - MSE) é formalizada por:

\[ J(\beta) = \frac{1}{2n} \sum_{i=1}^{n} \left( h_\beta(\mathbf{x}^{(i)}) - y^{(i)} ight)^2 = \frac{1}{2n} (\mathbf{X}\beta - \mathbf{y})^T (\mathbf{X}\beta - \mathbf{y}) \]

Onde \(\mathbf{X} \in \mathbb{R}^{n imes (p+1)}\) é a matriz de design contendo as \(n\) amostras e \(\mathbf{y} \in \mathbb{R}^n\) é o vetor de rótulos observados. O fator \(\frac{1}{2n}\) facilita as derivações analíticas do gradiente.

1.3 Resolução Analítica: Equação Normal

Para encontrar o vetor de parâmetros ideal \(\hat{\beta}\) que minimiza a função convexa \(J(\beta)\), calculamos a derivada parcial em relação a \(\beta\) e igualamos ao vetor nulo:

\[ \nabla_\beta J(\beta) = \frac{\partial}{\partial \beta} \left[ \frac{1}{2n} (\mathbf{X}\beta - \mathbf{y})^T (\mathbf{X}\beta - \mathbf{y}) ight] = \frac{1}{n} \mathbf{X}^T (\mathbf{X}\beta - \mathbf{y}) = 0 \] \[ \mathbf{X}^T \mathbf{X} \beta = \mathbf{X}^T \mathbf{y} \]

Isolando \(\beta\), obtemos a Equação Normal (Closed-form Analytical Solution):

\[ \hat{\beta}_{OLS} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y} \]
Limitações Computacionais da Equação Normal em Produção:

A inversão da matriz \(\mathbf{X}^T \mathbf{X} \in \mathbb{R}^{(p+1) imes (p+1)}\) possui complexidade computacional de \(\mathcal{O}(p^3)\). Quando o número de atributos \(p\) é grande (ex: \(p > 10.000\)), a inversão torna-se impraticável em termos de memória e tempo de CPU. Além disso, se houver alta multicolinearidade entre variáveis, \(\mathbf{X}^T \mathbf{X}\) torna-se quase-singular (determinante próximo de zero), resultando em alta instabilidade numérica e variância extrema dos coeficientes.

1.4 Otimização Iterativa: Gradiente Descendente

Quando a inversão analítica é inviável devido a Big Data (\(n \gg 1.000.000\)) ou alta dimensionalidade (\(p \gg 1.000\)), utiliza-se o algoritmo de Gradiente Descendente (Gradient Descent). A cada iteração \(k\), os coeficientes são atualizados na direção oposta ao gradiente da função de custo:

\[ \beta^{(k+1)} := \beta^{(k)} - \alphalpha \nabla_\beta J(\beta^{(k)}) = \beta^{(k)} - \alphalpha \frac{1}{n} \mathbf{X}^T (\mathbf{X}\beta^{(k)} - \mathbf{y}) \]

Onde \(\alphalpha > 0\) representa a taxa de aprendizado (learning rate). As três variantes principais de otimização em engenharia de IA são:

  • Batch Gradient Descent (BGD): Utiliza todas as \(n\) amostras para calcular o gradiente exato a cada iteração. Estável, mas lento para grandes volumes armazenados em S3.
  • Stochastic Gradient Descent (SGD): Atualiza os parâmetros a cada amostra individual. Extremamente rápido, mas apresenta alta variância na convergência.
  • Mini-Batch Gradient Descent (MBGD): Computa o gradiente sobre um subconjunto de amostras (ex: batch size = 64, 256, 512). Combina aceleração via GPU/VPU com vetorização em memória.

1.5 Regularização: Ridge (L2), Lasso (L1) e ElasticNet

A regularização adiciona uma penalidade à função de custo OLS para conter a magnitude dos coeficientes, evitando overfitting e contornando a multicolinearidade.

Regressão Ridge (Regularização L2)

Adiciona a norma L2 dos coeficientes ao erro quadrático:

\[ J_{Ridge}(\beta) = \frac{1}{2n} \|\mathbf{X}\beta - \mathbf{y}\|_2^2 + \lambda \|\beta\|_2^2 = \frac{1}{2n} (\mathbf{X}\beta - \mathbf{y})^T (\mathbf{X}\beta - \mathbf{y}) + \lambda \sum_{j=1}^{p} \beta_j^2 \]

A solução analítica da Regressão Ridge garante invertibilidade mesmo com multicolinearidade perfeita:

\[ \hat{\beta}_{Ridge} = (\mathbf{X}^T \mathbf{X} + \lambda \mathbf{I})^{-1} \mathbf{X}^T \mathbf{y} \]

Onde \(\lambda \ge 0\) é o hiperparâmetro de regularização. A adição de \(\lambda \mathbf{I}\) adiciona um valor positivo à diagonal principal de \(\mathbf{X}^T \mathbf{X}\), garantindo que a matriz resultante seja estritamente positiva definida e inversível.

Regressão Lasso (Regularização L1)

Adiciona a norma L1 dos coeficientes, promovendo esparsidade (Feature Selection automática):

\[ J_{Lasso}(\beta) = \frac{1}{2n} \|\mathbf{X}\beta - \mathbf{y}\|_2^2 + \lambda \|\beta\|_1 = \frac{1}{2n} (\mathbf{X}\beta - \mathbf{y})^T (\mathbf{X}\beta - \mathbf{y}) + \lambda \sum_{j=1}^{p} |\beta_j| \]

Devido à não-diferenciabilidade da norma L1 na origem (\(\beta_j = 0\)), o Lasso utiliza otimização por Gradiente Subordinado (Subgradient Descent) ou Coordinate Descent, zerando coeficientes de variáveis irrelevantes.

ElasticNet

Combina as penalidades L1 e L2 balanceadas pelo hiperparâmetro \( ho \in [0, 1]\):

\[ J_{ElasticNet}(\beta) = J_{OLS}(\beta) + \lambda \left[ ho \|\beta\|_1 + \frac{1 - ho}{2} \|\beta\|_2^2 ight] \]

1.6 Quando Usar vs Quando NÃO Usar (Trade-offs de Produção)

✓ Quando Usar (Vantagens)

  • Alta Interpretabilidade: Coeficientes \(\beta_j\) representam o efeito marginal exato de cada variável no resultado final. Requisito em precificação e regulação bancária.
  • Incerteza Probabilística: Fornece intervalos de confiança e p-valores para testes de hipóteses sobre a significância das variáveis.
  • Inferência Sub-Milissegundo: A predição requer apenas um produto escalar \(\mathbf{x}^T \beta\), resultando em latência \(\mathcal{O}(p) < 0.1 ext{ ms}\) em CPUs leves.
  • Eficiência em Baixa Dimensionalidade: Treinamento instantâneo via Equação Normal para datasets com poucas colunas (\(p < 1.000\)).

✕ Quando NÃO Usar (Desvantagens)

  • Relações Não-Lineares Complexas: Incapaz de capturar não-linearidades sem engenharia manual de atributos (polinômios, splines, interações).
  • Sensibilidade a Outliers: A função de custo quadrática OLS eleva ao quadrado os erros, fazendo com que outliers distorçam drasticamente a reta ajustada.
  • Complexidade de Treinamento OLS \(\mathcal{O}(p^3)\): A Equação Normal falha para tabelas muito largas. Exige uso de Gradiente Descendente ou Spark MLlib no AWS EMR.
  • Multicolinearidade Sem Regularização: Coeficientes tornam-se voláteis se colunas tiverem correlação linear perfeita ou quase-perfeita.

1.8 Código Executável em Python: Treinamento MLOps com Scikit-Learn

O script abaixo implementa o ciclo completo de desenvolvimento MLOps para Regressão Linear com Regularização Ridge CV, incluindo semente reprodutível, divisão treino-teste, padronização z-score, métricas de avaliação e persistência de modelo.

import numpy as np
import pandas as pd
from sklearn.datasets import make_regression
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import RidgeCV
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score
import joblib

# 1. Configuração de Semente Reprodutível
SEED = 42
np.random.seed(SEED)

# 2. Criação de Dataset Sintético de Precificação Financeira
X_raw, y_raw = make_regression(
    n_samples=1000,
    n_features=10,
    n_informative=6,
    noise=12.5,
    random_state=SEED
)

feature_cols = [f"feature_{i+1}" for i in range(10)]
df = pd.DataFrame(X_raw, columns=feature_cols)
df["target_price"] = y_raw

# 3. Separação em Treino e Teste (80/20)
X_train, X_test, y_train, y_test = train_test_split(
    df[feature_cols], df["target_price"], test_size=0.20, random_state=SEED
)

# 4. Pré-processamento: Padronização Z-Score (StandardScaler)
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# 5. Treinamento do Modelo com Validação Cruzada Automática (RidgeCV)
alphas = np.logspace(-3, 3, 100)
ridge_model = RidgeCV(alphas=alphas, cv=5, scoring="neg_mean_squared_error")
ridge_model.fit(X_train_scaled, y_train)

# 6. Avaliação de Métricas de Desempenho no Teste
y_pred = ridge_model.predict(X_test_scaled)
mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
mae = mean_absolute_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

print(f"--- RESULTADOS REGRESSÃO LINEAR RIDGE ---")
print(f"Alpha Ótimo Encontrado (λ): {ridge_model.alpha_:.4f}")
print(f"RMSE (Root Mean Squared Error): {rmse:.4f}")
print(f"MAE (Mean Absolute Error):     {mae:.4f}")
print(f"R² Score (Coeficiente Det.):   {r2:.4f}")

# 7. Persistência do Modelo e Scaler para MLOps
artifact_payload = {
    "model": ridge_model,
    "scaler": scaler,
    "feature_names": feature_cols,
    "optimal_alpha": ridge_model.alpha_
}
joblib.dump(artifact_payload, "linear_ridge_model.joblib")
print("Artefato MLOps salvo com sucesso em 'linear_ridge_model.joblib'.")

Seção 2: Regressão Logística (Logistic Regression)

Modelagem probabilística para classificação binária e multiclasse, função sigmoide, otimização de log-loss via Máxima Verossimilhança e extensão Softmax.

2.1 Intuição Matemática e a Função Sigmoide

A Regressão Logística é o algoritmo padrão para classificação binária probabilística. Em vez de prever diretamente o rótulo discreto \(y \in \{0, 1\}\), o modelo estima a probabilidade condicional de a observação pertencer à classe positiva: \(P(y=1|\mathbf{x}) = h_ heta(\mathbf{x})\).

Para mapear a combinação linear de atributos \( heta^T \mathbf{x} \in (-\infty, +\infty)\) no intervalo válido de probabilidade \((0, 1)\), aplica-se a Função Sigmoide (Logística) \(\sigma(z)\):

\[ h_ heta(\mathbf{x}) = \sigma( heta^T \mathbf{x}) = \frac{1}{1 + e^{- heta^T \mathbf{x}}} = \frac{e^{ heta^T \mathbf{x}}}{1 + e^{ heta^T \mathbf{x}}} \]
Propriedades Matemáticas Notáveis da Sigmoide:
  • Limites Assimptóticos: \(\lim_{z o +\infty} \sigma(z) = 1\) e \(\lim_{z o -\infty} \sigma(z) = 0\).
  • Ponto de Inflexão Central: \(\sigma(0) = 0,5\). Se \( heta^T \mathbf{x} > 0 \implies P(y=1) > 0,5\).
  • Derivada Elegante: A derivada de \(\sigma(z)\) em relação a \(z\) expressa-se em termos da própria função: \[ \sigma'(z) = \frac{d}{dz} \left( \frac{1}{1 + e^{-z}} ight) = \sigma(z) (1 - \sigma(z)) \] Essa propriedade simplifica imensamente o cálculo das atualizações por gradiente.

2.2 A Razão de Chances (Odds Ratio) e a Transformação Logit

A probabilidade de sucesso \(p = P(y=1|\mathbf{x})\) em relação à probabilidade de falha \(1 - p\) define a Razão de Chances (Odds Ratio):

\[ ext{Odds} = \frac{p}{1 - p} = \frac{\frac{1}{1 + e^{- heta^T \mathbf{x}}}}{1 - \frac{1}{1 + e^{- heta^T \mathbf{x}}}} = e^{ heta^T \mathbf{x}} \]

Aplicando o logaritmo natural à Razão de Chances, obtemos a Transformação Logit, demonstrando que o log-odds é uma combinação estritamente linear dos atributos:

\[ ext{logit}(p) = \ln\left( \frac{P(y=1|\mathbf{x})}{1 - P(y=1|\mathbf{x})} ight) = heta^T \mathbf{x} = heta_0 + heta_1 x_1 + \dots + heta_p x_p \]

2.3 Função de Custo: Log-Loss / Entropia Cruzada Binária

O uso da função de erro quadrático médio (MSE) na Regressão Logística resultaria em uma superfície não-convexa com múltiplos mínimos locais devido à não-linearidade da sigmoide. Por isso, utiliza-se a Estimativa de Máxima Verossimilhança (MLE).

A função de verossimilhança para \(n\) observações independentes de Bernoulli é dada por:

\[ L( heta) = \prod_{i=1}^{n} \left( h_ heta(\mathbf{x}^{(i)}) ight)^{y^{(i)}} \left( 1 - h_ heta(\mathbf{x}^{(i)}) ight)^{1 - y^{(i)}} \]

Minimizar o negativo do logaritmo da verossimilhança (Negative Log-Likelihood) nos dá a função de custo Log-Loss / Entropia Cruzada Binária (Binary Cross-Entropy):

\[ J( heta) = -\frac{1}{n} \ln L( heta) = -\frac{1}{n} \sum_{i=1}^{n} \left[ y^{(i)} \ln\left(h_ heta(\mathbf{x}^{(i)}) ight) + (1 - y^{(i)}) \ln\left(1 - h_ heta(\mathbf{x}^{(i)}) ight) ight] \]

O gradiente de \(J( heta)\) em relação a \( heta\) possui a mesma forma visual da regressão linear:

\[ \nabla_ heta J( heta) = \frac{1}{n} \mathbf{X}^T \left( \sigma(\mathbf{X} heta) - \mathbf{y} ight) \]

2.4 Fronteira de Decisão e Extensões Multiclasse

A Fronteira de Decisão (Decision Boundary) é o hiperplano geométrico que separa as classes. Para um limiar padrão \( au = 0,5\):

\[ \hat{y} = 1 \iff P(y=1|\mathbf{x}) \ge 0,5 \iff heta^T \mathbf{x} \ge 0 \]

Regressão Logística Multinomial (Softmax)

Para problemas com \(K > 2\) classes mutuamente exclusivas, substitui-se a sigmoide pela função Softmax:

\[ P(y = k | \mathbf{x}) = \frac{e^{ heta_k^T \mathbf{x}}}{\sum_{j=1}^{K} e^{ heta_j^T \mathbf{x}}} \]

Modelo Probit

Usa a distribuição acumulada normal padrão \(\Phi(z)\) em vez da função sigmoide: \(P(y=1|\mathbf{x}) = \Phi( heta^T \mathbf{x})\), amplamente utilizada em econometria financeira.

2.5 Quando Usar vs Quando NÃO Usar (Trade-offs de Produção)

✓ Quando Usar (Vantagens)

  • Probabilidades Calibradas: Retorna probabilidades entre 0 e 1, permitindo ajustar limiares de decisão (\( au\)) conforme a matriz de custos de negócio.
  • Explicabilidade Regulatória (Scorecards): Os coeficientes exp(\( heta_j\)) medem a variação exata nas chances de inadimplência (regulação BACEN/Basileia).
  • Extrema Velocidade em Tempo Real: Inferência requer apenas cálculo sigmoidal simples (\(< 0,5 ext{ ms}\) por chamada de API).
  • Resistência ao Overfitting: Regularizações L1/L2 integradas contêm modelos com muitos atributos.

✕ Quando NÃO Usar (Desvantagens)

  • Fronteiras Linearmente Separáveis: Falha se os dados exigirem separação não-linear complexa em forma de espiral ou círculos concêntricos.
  • Vulnerabilidade a Desbalanceamento Extremo: Em cenários de fraude onde a classe positiva é 0,01%, requer calibração de pesos de classe (`class_weight='balanced'`) ou Oversampling (SMOTE).
  • Sensibilidade a Outliers Extremos: Observações muito distantes podem distorcer o alinhamento da fronteira de decisão.

2.7 Código Executável em Python: Classificação de Crédito com Log-Loss

O código Python a seguir gera um dataset sintético de risco de crédito, treina uma Regressão Logística com validação de hiperparâmetro \(C\), calcula ROC-AUC, matriz de confusão e serializa a solução.

import numpy as np
import pandas as pd
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score, log_loss, confusion_matrix, classification_report
import joblib

# 1. Semente para Reprodutibilidade
SEED = 42
np.random.seed(SEED)

# 2. Geração de Dataset Sintético de Scorecard de Crédito (Inadimplência)
X_raw, y_raw = make_classification(
    n_samples=1200,
    n_features=8,
    n_informative=5,
    n_redundant=1,
    weights=[0.80, 0.20],  # 20% Taxa de Inadimplência
    random_state=SEED
)

features = [
    "renda_mensal", "taxa_endividamento", "historico_atrasos",
    "idade_score", "linhas_credito_ativas", "utilizacao_limite",
    "saldo_investimento", "consultas_recentes"
]

df_credit = pd.DataFrame(X_raw, columns=features)
df_credit["inadimplente"] = y_raw

# 3. Divisão Treino e Teste Estratificada
X_train, X_test, y_train, y_test = train_test_split(
    df_credit[features], df_credit["inadimplente"], test_size=0.20, random_state=SEED, stratify=df_credit["inadimplente"]
)

# 4. Normalização dos Atributos
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# 5. Treinamento da Regressão Logística L2
model_logit = LogisticRegression(C=1.0, solver="lbfgs", max_iter=1000, random_state=SEED)
model_logit.fit(X_train_scaled, y_train)

# 6. Métricas de Avaliação Probabilística
y_pred_proba = model_logit.predict_proba(X_test_scaled)[:, 1]
y_pred_class = (y_pred_proba >= 0.50).astype(int)

auc = roc_auc_score(y_test, y_pred_proba)
loss = log_loss(y_test, y_pred_proba)
cm = confusion_matrix(y_test, y_pred_class)

print("--- RESULTADOS REGRESSÃO LOGÍSTICA ---")
print(f"ROC-AUC Score: {auc:.4f}")
print(f"Log-Loss (Binary Cross-Entropy): {loss:.4f}")
print("Matriz de Confusão:")
print(cm)
print("\nRelatório de Classificação Detalhado:")
print(classification_report(y_test, y_pred_class))

# 7. Serialização do Modelo e Artefatos MLOps
artifact = {
    "model": model_logit,
    "scaler": scaler,
    "feature_list": features,
    "threshold": 0.50
}
joblib.dump(artifact, "logistic_credit_model.joblib")

Seção 3: Árvore de Decisão (Decision Tree - CART Algorithm)

Modelagem não-paramétrica por particionamento recursivo do espaço de atributos, métricas de impureza (Gini, Entropia, MSE) e pós-poda por complexidade de custo (Cost-Complexity Pruning).

3.1 O Algoritmo CART e Particionamento Recursivo do Espaço

O algoritmo CART (Classification and Regression Trees) constrói árvores binárias através do particionamento guloso e recursivo do espaço de entrada \(\mathcal{X} \subset \mathbb{R}^p\) em regiões ortogonais disjuntas \(R_1, R_2, \dots, R_M\).

A cada nó de decisão, o algoritmo seleciona o par atributo-ponto de corte \((j, s)\) que maximiza a redução de impureza (ou variância), dividindo o espaço no meio-espaço esquerdo \(R_1(j, s) = \{\mathbf{x} | x_j \le s\}\) e direito \(R_2(j, s) = \{\mathbf{x} | x_j > s\}\).

3.2 Métricas de Impureza: Gini vs Entropia vs MSE

1. Impureza de Gini (Gini Impurity - Classificação)

Mede a probabilidade de um elemento selecionado aleatoriamente ser rotulado incorretamente se for classificado de acordo com a distribuição das classes no nó \(D\):

\[ ext{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^2 \]

Onde \(p_k\) é a proporção de observações pertencentes à classe \(k\) no nó \(D\). Quando o nó é 100% puro (todas as observações pertencem a uma única classe), \( ext{Gini}(D) = 0\).

2. Entropia e Ganho de Informação (Information Gain - Classificação)

Baseada na Teoria da Informação de Shannon, a Entropia mede a desordem ou incerteza no nó \(D\):

\[ H(D) = -\sum_{k=1}^{K} p_k \log_2(p_k) \]

O Ganho de Informação (Information Gain) ao dividir o nó \(D\) pelo atributo \(A\) é a diferença entre a entropia pai e a média ponderada das entropias dos filhos:

\[ IG(D, A) = H(D) - \sum_{v \in ext{Filhos}} \frac{|D_v|}{|D|} H(D_v) \]

3. Critério para Árvores de Regressão (Redução de Variância / MSE)

Em problemas de regressão onde a variável resposta é contínua, o critério de partição é a minimização da variância residual (MSE):

\[ ext{MSE}(D) = \frac{1}{|D|} \sum_{i \in D} \left( y^{(i)} - \bar{y}_D ight)^2 \]

Onde \(\bar{y}_D = \frac{1}{|D|} \sum_{i \in D} y^{(i)}\) é o valor médio predito nas folhas do nó \(D\).

3.3 Poda (Pruning) e Hiperparâmetros de Regularização

Sem restrições, uma Árvore de Decisão continuará crescendo até que cada nó folha contenha apenas 1 amostra, resultando em overfitting severo (memorização de ruído).

A técnica principal para evitar o sobreajuste é a Poda por Complexidade de Custo (Cost-Complexity Pruning), que minimiza a seguinte função de custo penalizada:

\[ R_\alphalpha(T) = R(T) + \alphalpha |T| \]

Onde \(R(T)\) é a impureza total das folhas da árvore \(T\), \(|T|\) é o número de nós folha terminais, e \(\alphalpha \ge 0\) é o parâmetro de penalidade por complexidade. Ao aumentar \(\alphalpha\), nós ramificados redundantes são podados.

Principais Hiperparâmetros de Controle na Scikit-Learn:
  • max_depth: Limita a profundidade máxima da árvore. Previne ramificações excessivamente profundas.
  • min_samples_split: Número mínimo de amostras necessárias para autorizar a divisão de um nó interno.
  • min_samples_leaf: Número mínimo de amostras que uma folha terminal deve conter.
  • ccp_alpha: Hiperparâmetro da poda Cost-Complexity (\(\alphalpha\)). Selecionado via validação cruzada.

3.4 Quando Usar vs Quando NÃO Usar (Trade-offs de Produção)

✓ Quando Usar (Vantagens)

  • Sem Necessidade de Escalamento: É invariante a transformações monotônicas nos atributos. Não requer z-score nem MinMax scaling.
  • Lida Nativa com Tipos Mistos: Aceita variáveis numéricas e categóricas sem necessidade prévia de codificação complexa.
  • Extração de Regras Comerciais: Permite exportar a estrutura da árvore em formato `if-then-else` para sistemas legados de motor de regras.
  • Captura Interações Não-Lineares: Descobre automaticamente interações complexas entre atributos sem especificação prévia.

✕ Quando NÃO Usar (Desvantagens)

  • Alta Instabilidade (Alta Variância): Pequenas alterações no dataset de treino podem alterar completamente a estrutura da árvore.
  • Divisões Apenas Ortogonais: Dificuldade para aproximar fronteiras diagonais ou funções suaves, criando passos escada.
  • Incapacidade de Extrapolação: Em regressão, uma árvore nunca pode prever valores fora do intervalo observado no treino.

3.6 Código Executável em Python: Treinamento e Extração de Regras CART

O script Python abaixo realiza o treinamento de uma Árvore de Decisão CART (`DecisionTreeClassifier`), aplicando poda por complexidade de custo, calculando a importância dos atributos e exportando a estrutura de regras em formato legível.

import numpy as np
import pandas as pd
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.metrics import accuracy_score, f1_score, precision_score, recall_score
import joblib

# 1. Semente Aleatória Reprodutível
SEED = 42
np.random.seed(SEED)

# 2. Dataset Sintético de Aprovacao de Subscrição de Seguro
X_raw, y_raw = make_classification(
    n_samples=1500,
    n_features=6,
    n_informative=4,
    n_clusters_per_class=2,
    random_state=SEED
)

features = [
    "renda_mensal", "valor_apolice", "anos_emprego",
    "divida_existente", "historico_sinistros", "valor_garantia"
]

df_underwriting = pd.DataFrame(X_raw, columns=features)
df_underwriting["status_aprovacao"] = y_raw

# 3. Divisão Treino e Teste
X_train, X_test, y_train, y_test = train_test_split(
    df_underwriting[features], df_underwriting["status_aprovacao"], test_size=0.20, random_state=SEED
)

# 4. Treinamento com Poda Cost-Complexity (ccp_alpha) e Limite de Profundidade
dt_model = DecisionTreeClassifier(
    criterion="gini",
    max_depth=5,
    min_samples_split=20,
    min_samples_leaf=10,
    ccp_alpha=0.005,
    random_state=SEED
)
dt_model.fit(X_train, y_train)

# 5. Avaliação do Modelo no Conjunto de Teste
y_pred = dt_model.predict(X_test)
acc = accuracy_score(y_test, y_pred)
f1 = f1_score(y_test, y_pred)
prec = precision_score(y_test, y_pred)
rec = recall_score(y_test, y_pred)

print("--- RESULTADOS ÁRVORE DE DECISÃO (CART) ---")
print(f"Acurácia no Teste:  {acc:.4f}")
print(f"F1-Score:          {f1:.4f}")
print(f"Precisão:          {prec:.4f}")
print(f"Revocação (Recall): {rec:.4f}")

# 6. Extração de Regras Textuais para Auditoria
tree_rules = export_text(dt_model, feature_names=features)
print("\n--- ESTRUTURA DE REGRAS EXTRAÍDAS DA ÁRVORE ---")
print("\n".join(tree_rules.split("\n")[:10]))

# 7. Importância dos Atributos (Feature Importances)
importances = pd.Series(dt_model.feature_importances_, index=features).sort_values(ascending=False)
print("\nImportância dos Atributos:")
print(importances)

# 8. Persistência do Modelo para MLOps
artifact_dt = {
    "model": dt_model,
    "feature_names": features,
    "feature_importances": importances.to_dict(),
    "rules_text": tree_rules
}
joblib.dump(artifact_dt, "decision_tree_underwriting.joblib")
print("\nModelo de Árvore de Decisão salvo com sucesso em 'decision_tree_underwriting.joblib'.")

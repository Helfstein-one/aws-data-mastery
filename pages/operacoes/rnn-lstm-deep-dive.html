O que é RNN? Processamento de Sequências Temporais

Por que RNNs são ideais para dados sequenciais e como mantêm "memória" de estados anteriores.

Uma Recurrent Neural Network (RNN) é uma arquitetura neural especializada em processar dados sequenciais (séries temporais, texto, áudio). Diferentemente de CNNs que processam dados espacialmente, RNNs processam dados temporalmente, mantendo uma "memória" de estados anteriores.

Imagine que você está lendo um livro. Cada palavra que você lê depende das palavras anteriores para fazer sentido. Seu cérebro mantém um contexto ("hidden state") do que você leu até agora. RNNs funcionam assim: em cada passo temporal, recebem uma entrada atual e o estado oculto (memória) do passo anterior, processam ambos, e produzem uma saída e um novo estado oculto.

Recorrência: O Conceito Fundamental

A recorrência é a chave: a mesma rede neural é aplicada repetidamente a cada passo de tempo, com a saída anterior alimentando a próxima entrada. Formalmente:

ℹ️ Equação Simples de RNN:
h_t = tanh(W_h × h_{t-1} + W_x × x_t + b)
y_t = W_y × h_t + b_y

Onde:
- h_t = estado oculto no tempo t
- x_t = entrada no tempo t
- W_h, W_x, W_y = pesos aprendidos
- tanh = função de ativação

Tipos de Sequências Processadas

Muitos-para-Um

Sequência → Classe única. Ex: análise de sentimento (texto → positivo/negativo).

Um-para-Muitos

Entrada única → Sequência. Ex: legendas de imagens (imagem → série de palavras).

Muitos-para-Muitos

Sequência → Sequência. Ex: tradução (inglês → português, palavra a palavra).

02

Conceitos-Chave: Estado Oculto, BPTT & Gradientes Desaparecidos

Os desafios técnicos e como LSTMs resolvem.

Estado Oculto (Hidden State)

O estado oculto h_t é a "memória" da RNN. Ele contém informações sobre todas as entradas anteriores. Durante o treinamento, a rede aprende a atualizar este estado de forma que seja útil para a tarefa.

Desafio: Como manter informações relevantes ao longo de muitos passos de tempo? Estados iniciais gradualmente "desaparecem".

Backpropagation Through Time (BPTT)

BPTT é o algoritmo de aprendizagem para RNNs. Funciona desdobrando a rede ao longo do tempo (imaginando uma rede feedforward separada para cada passo de tempo), depois aplicando backpropagation padrão.

Exemplo mental: Se você tem 100 passos de tempo, você trata isso como uma rede neural muito profunda (100 camadas)!

Vanishing Gradient Problem (Gradientes Desaparecidos)

Este é o maior desafio das RNNs simples. Durante backpropagation através de muitos passos de tempo, os gradientes se multiplicam repetidamente por pesos (que são frequentemente <1), causando que gradientes exponencialmente diminuam.

⚠️ Problema: Uma RNN simples não consegue aprender dependências de longo prazo. Se uma informação importante ocorreu 50 passos atrás, é praticamente impossível que ela influencie a saída atual.

Solução: LSTMs (Long Short-Term Memory) foram inventadas para resolver exatamente este problema.

Exploding Gradients

O oposto também pode ocorrer: se pesos são >1, gradientes podem explodir exponencialmente, tornando treinamento instável.

Solução simples: Gradient clipping - limitar o valor máximo de gradientes durante atualização.

03

LSTM Architecture: Portas Forget, Input & Output

Como LSTMs mantêm memória de longo prazo e processam sequências.

Estrutura Interna de uma Célula LSTM

Uma célula LSTM contém três "portas" (gates) que controlam o fluxo de informação. Cada porta é uma mini rede neural que decide quanto de informação deixar passar:


[Entrada x_t + Estado anterior h_{t-1}]
         ↓
    [FORGET GATE: f_t = σ(W_f × [h_{t-1}, x_t] + b_f)]
    ↓ (Quanto esquecer do estado anterior)
    
    [INPUT GATE: i_t = σ(W_i × [h_{t-1}, x_t] + b_i)]
    [CANDIDATE: C̃_t = tanh(W_c × [h_{t-1}, x_t] + b_c)]
    ↓ (Quanto da entrada nova adicionar)
    
    [CELL STATE UPDATE: C_t = f_t * C_{t-1} + i_t * C̃_t]
    ↓ (Memória de longo prazo)
    
    [OUTPUT GATE: o_t = σ(W_o × [h_{t-1}, x_t] + b_o)]
    [HIDDEN STATE: h_t = o_t * tanh(C_t)]
    ↓
[Saída y_t & Estado para próximo passo]

As Três Portas Explicadas

Forget Gate (Porta Esquecida)

Decide quanto do estado anterior descartar. Valor perto de 0 = esquecer, valor perto de 1 = lembrar.

Exemplo: Em análise de sentimento, quando encontra pontuação, "esquece" contexto anterior.

Input Gate (Porta de Entrada)

Decide quanto da entrada nova adicionar ao estado. Valor perto de 0 = ignorar entrada, perto de 1 = absorver.

Exemplo: Quando detecta adjetivo importante, aumenta gate de entrada.

Output Gate (Porta de Saída)

Controla quanto do estado interno é exposto como saída/estado oculto.

Exemplo: Processa informação interna, mas apenas expõe o relevante.

Por que LSTMs Resolvem Gradientes Desaparecidos?

A chave é a "rodovia de célula" (cell state). O gradiente pode fluir diretamente através de adições nas portas, ao invés de multiplicações repetidas. Isso permite que informações de longo prazo sejam propagadas com gradientes que não desaparecem.

✅ Resultado: LSTMs conseguem aprender dependências de sequências com 100+ passos de tempo, vs RNNs simples que falham além de ~10 passos.

GRU: LSTM Simplificada

Gated Recurrent Unit (GRU) é uma variação mais simples de LSTM com apenas 2 portas (reset e update) ao invés de 3. Frequentemente funciona tão bem quanto LSTM com menos parâmetros, melhor para dados menores.

Implementação Prática: RNN, LSTM, GRU em PyTorch e TensorFlow

Código testado para séries temporais e análise de sequências.

Exemplo 1: RNN Simples em PyTorch

import torch
import torch.nn as nn
import torch.optim as optim

# 1. Definir RNN simples
class SimpleRNN(nn.Module):
    def __init__(self, input_size=1, hidden_size=50, output_size=1):
        super().__init__()
        self.rnn = nn.RNN(input_size, hidden_size, batch_first=True)
        self.fc = nn.Linear(hidden_size, output_size)

    def forward(self, x, h_prev=None):
        # x shape: (batch, seq_len, input_size)
        out, h_n = self.rnn(x, h_prev)  # out: (batch, seq_len, hidden_size)
        predictions = self.fc(out)       # (batch, seq_len, output_size)
        return predictions, h_n

# 2. Gerar dados simulados de série temporal
seq_length = 20
num_samples = 100
t = torch.linspace(0, 10*3.14, seq_length*num_samples)
data = torch.sin(t).reshape(num_samples, seq_length, 1)

# 3. Treinar modelo
model = SimpleRNN(input_size=1, hidden_size=50, output_size=1)
optimizer = optim.Adam(model.parameters(), lr=0.01)
criterion = nn.MSELoss()

for epoch in range(50):
    total_loss = 0
    for i in range(num_samples):
        x = data[i:i+1]
        y = data[i:i+1].clone()  # Target = input (próxima predição)
        
        predictions, _ = model(x)
        loss = criterion(predictions, y)
        
        optimizer.zero_grad()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # Evitar gradientes explodindo
        optimizer.step()
        
        total_loss += loss.item()
    
    if (epoch + 1) % 10 == 0:
        print(f"Epoch {epoch+1}, Loss: {total_loss/num_samples:.4f}")

# 4. Inference
model.eval()
with torch.no_grad():
    future_steps = 10
    current_x = data[0:1].clone()
    predictions = []
    for _ in range(future_steps):
        pred, _ = model(current_x)
        next_val = pred[0, -1:, :]  # Última predição
        predictions.append(next_val.item())
        current_x = torch.cat([current_x[:, 1:, :], next_val.unsqueeze(1)], dim=1)
    
    print(f"Próximas 10 predições: {predictions}")

Exemplo 2: LSTM para Previsão de Preços de Ações (TensorFlow/Keras)

import tensorflow as tf
from tensorflow.keras import layers, models
import numpy as np

# 1. Preparar dados de preço de ações
def prepare_stock_data(prices, look_back=60):
    """Converte série de preços em dataset de janelas de treino."""
    X, y = [], []
    for i in range(len(prices) - look_back):
        X.append(prices[i:i+look_back])
        y.append(prices[i+look_back])
    return np.array(X), np.array(y)

# Carregar dados reais (exemplo com yfinance)
import yfinance as yf
stock_data = yf.download('AAPL', start='2020-01-01', end='2024-01-01')
prices = stock_data['Close'].values

# Normalizar
prices_normalized = (prices - prices.mean()) / prices.std()

# Preparar dados
look_back = 60  # Usar 60 dias anteriores para prever 1 dia
X, y = prepare_stock_data(prices_normalized, look_back)

# Split treino/teste (80/20)
split = int(0.8 * len(X))
X_train, X_test = X[:split], X[split:]
y_train, y_test = y[:split], y[split:]

# 2. Definir modelo LSTM
model = models.Sequential([
    layers.LSTM(64, activation='relu', input_shape=(look_back, 1), return_sequences=True),
    layers.Dropout(0.2),
    layers.LSTM(32, activation='relu', return_sequences=False),
    layers.Dropout(0.2),
    layers.Dense(16, activation='relu'),
    layers.Dense(1)
])

# 3. Compilar e treinar
model.compile(optimizer='adam', loss='mse', metrics=['mae'])
history = model.fit(
    X_train, y_train,
    validation_data=(X_test, y_test),
    epochs=50,
    batch_size=32,
    verbose=1
)

# 4. Fazer predições e avaliar
predictions = model.predict(X_test)

# Desnormalizar para comparar com valores reais
pred_prices = predictions * prices_normalized.std() + prices_normalized.mean()
actual_prices = y_test * prices_normalized.std() + prices_normalized.mean()

# Calcular erro
rmse = np.sqrt(np.mean((pred_prices - actual_prices)**2))
print(f"RMSE: ${rmse:.2f}")
print(f"Preço real último dia: ${actual_prices[-1]:.2f}")
print(f"Predição LSTM: ${pred_prices[-1][0]:.2f}")

Exemplo 3: Bidirectional RNN (PyTorch)

import torch
import torch.nn as nn

# RNN bidirecional processa sequência em ambas as direções
# Útil para tarefas onde contexto futuro e passado são importantes

class BidirectionalLSTM(nn.Module):
    def __init__(self, input_size=1, hidden_size=50, num_layers=2, output_size=1):
        super().__init__()
        self.lstm = nn.LSTM(
            input_size, hidden_size, num_layers,
            bidirectional=True,  # Processar em ambas direções
            batch_first=True
        )
        # Output de bidirectional = 2 * hidden_size (concatenação)
        self.fc = nn.Linear(2 * hidden_size, output_size)

    def forward(self, x):
        # x shape: (batch, seq_len, input_size)
        out, _ = self.lstm(x)  # out: (batch, seq_len, 2*hidden_size)
        # Tomar apenas última posição
        last_out = out[:, -1, :]
        predictions = self.fc(last_out)
        return predictions

# Usar em análise de sentimento (precisa de contexto anterior E posterior)
model = BidirectionalLSTM(input_size=100, hidden_size=50, num_layers=2, output_size=2)
# Input: batch de sequências de embeddings
# Output: sentimento (2 classes: positivo/negativo)

Exemplo 4: GRU vs LSTM (Comparação)

import time

# GRU tem menos parâmetros e treina mais rápido
gru_model = nn.GRU(input_size=100, hidden_size=50, num_layers=2, batch_first=True)
lstm_model = nn.LSTM(input_size=100, hidden_size=50, num_layers=2, batch_first=True)

# Contar parâmetros
def count_params(model):
    return sum(p.numel() for p in model.parameters())

gru_params = count_params(gru_model)
lstm_params = count_params(lstm_model)

print(f"GRU parâmetros: {gru_params}")           # ~49,500
print(f"LSTM parâmetros: {lstm_params}")         # ~66,000
print(f"Relação LSTM/GRU: {lstm_params/gru_params:.2f}x")  # ~1.33x maior

# Na prática: GRU é ~30% mais rápido, accuracy similar
# Usar GRU para dados menores, LSTM para dados grandes

Modelos de Sequência Avançados: Encoder-Decoder & Attention

Além de RNN simples: processamento de sequências complexas.

Encoder-Decoder (Seq2Seq)

Arquitetura para tarefas que transformam uma sequência em outra (tradução, summarização):


[Sequência de Entrada: "Hello world"]
          ↓
     [ENCODER (RNN/LSTM)]
          ↓
     [Context Vector: z]
     (resumo comprimido da entrada)
          ↓
     [DECODER (RNN/LSTM)]
          ↓
[Sequência de Saída: "Olá mundo"]

O encoder processa a sequência de entrada e produz um "context vector" (resumo denso). O decoder recebe este vetor e gera a sequência de saída palavra por palavra.

Attention Mechanism (Atenção)

Problema: Context vector de tamanho fixo não consegue capturar sequências longas. Solução: Attention permite que decoder "olhe para" partes específicas do encoder em cada passo.

Exemplo: Ao traduzir "O gato sentou no tapete", ao gerar palavra "gato" em português, o attention score aumenta na palavra "cat" da entrada.

✅ Transformers (Vistos em outra página) generalizam attention para toda a arquitetura, dispensando recorrência completamente.

RNN vs Transformer: Trade-offs e Quando Usar

Comparação de arquiteturas para sequências.

Aspecto RNN/LSTM Transformer
Processamento Sequencial (passo a passo) Paralelo (todos os passos simultaneamente)
Velocidade de Treino Lenta (O(n) em sequência) Rápida (O(1) paralelável)
Latência de Inferência Rápida (gera token por token) Mais lenta (precisa processar contexto inteiro)
Memória de Longo Prazo LSTM resolve até ~100 passos Mais robusta, até milhares de tokens
Contexto Bidirecional Requer BiLSTM (2x parâmetros) Natural, sem penalidade
Interpretabilidade Média (análise de attention de célula) Alta (attention weights visualizáveis)
Dados Necessários Menos (funciona com dados pequenos) Mais (precisa de grande volume)
Caso de Uso Ideal Streaming, IoT, latência crítica NLP, processamento em lote, máxima accuracy

Quando NÃO Usar RNNs

⚠️ RNNs são menos populares hoje: Transformers dominam NLP. Mas RNNs ainda são melhores para:
• Dados streaming em tempo real (IoT, sensores)
• Modelos muito compactos (edge devices)
• Quando latência de inferência é crítica

Aplicação Financeira: Detecção de Fraude em Sequências de Transações

LSTM para análise de padrões anormais em tempo real.

Caso Real: Fraud Detection em Cartão de Crédito

Um banco processa 10 milhões de transações/dia. Cada cliente tem um padrão de gasto característico. Desvios deste padrão podem indicar fraude (cartão roubado, clonagem).

Abordagem Tradicional: Regras simples (ex: "mais de $5000 em 1 hora = alerta"). Muitos falsos positivos.

Abordagem LSTM: Treinar modelo que aprende o padrão temporal de cada cliente, então detecta anomalias sutis.

import torch
import torch.nn as nn
import numpy as np

# 1. Preparar dados de transações
def prepare_transaction_sequences(transactions, user_id, seq_len=30):
    """
    transactions: lista de {timestamp, amount, mcc, user_id}
    Retorna: sequências de transações passadas
    """
    user_transactions = [t for t in transactions if t['user_id'] == user_id]
    
    # Normalizar features
    amounts = np.array([t['amount'] for t in user_transactions])
    amounts_norm = (amounts - amounts.mean()) / (amounts.std() + 1e-6)
    
    # Criar features por transação
    X = []
    for i in range(len(amounts_norm) - seq_len):
        seq = amounts_norm[i:i+seq_len]
        X.append(seq)
    
    return np.array(X).reshape(-1, seq_len, 1)

# 2. Modelo LSTM para classificação (Fraude vs Normal)
class FraudDetectorLSTM(nn.Module):
    def __init__(self, input_size=1, hidden_size=64, output_size=2):
        super().__init__()
        self.lstm1 = nn.LSTM(input_size, hidden_size, batch_first=True, dropout=0.2)
        self.lstm2 = nn.LSTM(hidden_size, 32, batch_first=True)
        self.fc = nn.Sequential(
            nn.Linear(32, 16),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(16, output_size)
        )

    def forward(self, x):
        _, (h1, _) = self.lstm1(x)
        _, (h2, _) = self.lstm2(h1.unsqueeze(0).transpose(0, 1))
        output = self.fc(h2[-1])
        return output

# 3. Treinar modelo com dados balanceados
model = FraudDetectorLSTM()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
criterion = nn.CrossEntropyLoss(weight=torch.tensor([1.0, 5.0]))  # Pesar fraudes mais

# Suponha X_train, y_train: sequências e labels (0=normal, 1=fraude)
# y_train desbalanceado: 99.8% normal, 0.2% fraude

for epoch in range(20):
    for batch_x, batch_y in data_loader:
        pred = model(batch_x)
        loss = criterion(pred, batch_y)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

# 4. Deploy em produção (SageMaker Endpoint)
# Guardar modelo
torch.save(model.state_dict(), 'fraud_detector.pth')

# Real-time scoring:
model.eval()
def score_transaction_sequence(transaction_sequence):
    """Retorna probabilidade de fraude (0-1)"""
    x = torch.tensor(transaction_sequence).unsqueeze(0).float()
    with torch.no_grad():
        logits = model(x)
        probs = torch.softmax(logits, dim=1)
        fraud_prob = probs[0, 1].item()
    return fraud_prob

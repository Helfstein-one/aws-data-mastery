01

A Morte do OCR Clássico

Porque o Regex e bounding-boxes não escalam em documentos complexos.

Até pouco tempo, usávamos ferramentas de OCR (como AWS Textract tradicional) que dependiam fortemente de regras e coordenadas. O problema? Se o layout da fatura ou contrato mudasse 2 milímetros para a direita, os códigos Regex quebravam inteiros pipelines de dados.

Com os Modelos Multimodais (Vision) como o Claude 3.5 Sonnet, podemos passar os pixels brutos do documento direto para o modelo e pedir para ele inferir semanticamente onde os valores estão e exportar um JSON limpo e validado. Chamamos isso de ETL Cognitivo.

02

Arquitetura de Pipeline Multimodal

Da imagem bruta à tabela estruturada no Athena.

📌 Legenda & Arquitetura — Pipeline de ETL Cognitivo Multimodal:
  • Componentes AWS / Módulos: Amazon S3 (Buckets Raw & Clean), Amazon SQS, AWS Lambda, Amazon Bedrock (Claude 3.5 Vision).
  • Integração: Ingestão de arquivos de imagem/PDF via S3 Event Notifications e fila SQS, leitura em lote por AWS Lambda e extração cognitiva de dados via modelo Claude 3.5 Vision no Bedrock com salvamento em S3 Clean (JSON Lines).
  • Contexto: Processamento assíncrono escalável para transformação de documentos complexos não estruturados em dados estruturados.
Ingestão

Amazon S3 + SQS

O cliente envia PDFs escaneados para o bucket S3 RAW, enfileirando os eventos de forma desacoplada no SQS.

Processamento Cognitivo

Claude via Bedrock

A Lambda intercepta, converte arquivos para Base64 e exige que o LLM retorne um payload JSON pré-tipado, ignorando ruídos visuais.

Carga Analítica

AWS Glue & Athena

O JSON é validado por Pydantic (guardrails) e injetado em Iceberg, pronto para queries estruturadas (SQL).

03

Trade-offs de Processamento Documental

Quando usar OCR barato vs LLM robusto.

Processar imagens no Claude 3.5 Sonnet consome muitos tokens ($$$). Se você tem 1 milhão de documentos diários, é essencial entender os Trade-offs e até mesmo aplicar métodos híbridos.

Cenário de Dados Tecnologia Vencedora Prós / Contras
Milhões de recibos (Cupom Fiscal) todos com mesmo layout exato de uma loja. OCR Clássico (AWS Textract / Tesseract) Custo baixíssimo. A performance é alta porque a variação posicional X/Y é zero.
Contratos jurídicos diversos. Precisamos extrair multas, cláusulas e contratantes. Claude 3.5 Sonnet (Nativo Visão) Custo mais alto (Tokens), mas entende tabelas quebradas, jargões invisíveis e layouts aleatórios com perfeição.
10 Milhões de fichas médicas variadas. Orçamento estourado. Híbrido (Textract + LLaMA 3) Usa o Textract pra jogar todo texto "sujo" num arquivo. Passa esse texto barato para um LLaMA pequeno estruturar o JSON. Maior eficiência financeira.
O Script de Extração Base64 via Boto3 
import boto3
import json

bedrock = boto3.client('bedrock-runtime')

def extrair_dados_fatura(imagem_bytes):
    # Prompt forçando a saída em JSON estruturado
    prompt = """Retorne APENAS um JSON válido extraído desta fatura:
    - razao_social
    - valor_total
    - data_vencimento
    """
    
    body = json.dumps({
        "anthropic_version": "bedrock-2023-05-31",
        "max_tokens": 1000,
        "messages": [
            {
                "role": "user",
                "content": [
                    {"type": "image", "source": {"type": "base64", "media_type": "image/jpeg", "data": imagem_bytes}},
                    {"type": "text", "text": prompt}
                ]
            }
        ]
    })
    response = bedrock.invoke_model(modelId="anthropic.claude-3-5-sonnet-20240620-v1:0", body=body)
    return json.loads(response['body'].read())
04

Pipeline Multimodal em Produção — S3 + Textract + Bedrock

Processamento batch de documentos com error handling, retries e saída estruturada para RAG.

O código da seção anterior extrai dados de uma única imagem em memória. Em produção, os documentos chegam via S3, precisam de Textract para extração de layout/tabelas, e o resultado deve ser salvo de volta em S3 em formato estruturado para indexação no OpenSearch. O pipeline abaixo orquestra tudo isso com tratamento de erros e processamento em batch.

Pipeline Multimodal Completo — S3 → Textract → Bedrock → S3
import boto3, json, base64
from botocore.exceptions import ClientError

s3        = boto3.client("s3")
textract  = boto3.client("textract")
bedrock   = boto3.client("bedrock-runtime")

BUCKET_IN  = "documentos-entrada"
BUCKET_OUT = "documentos-processados"
MODEL_ID   = "anthropic.claude-3-5-sonnet-20240620-v1:0"

def extrair_texto_textract(bucket: str, key: str) -> str:
    resp = textract.detect_document_text(
        Document={"S3Object": {"Bucket": bucket, "Name": key}}
    )
    return " ".join(
        b["Text"] for b in resp["Blocks"] if b["BlockType"] == "LINE"
    )

def extrair_com_visao(bucket: str, key: str) -> dict:
    img_bytes = s3.get_object(Bucket=bucket, Key=key)["Body"].read()
    img_b64   = base64.b64encode(img_bytes).decode()

    prompt = (
        "Você é um extrator de dados. Retorne APENAS um JSON com os campos: "
        "fornecedor, cnpj, data_emissao, valor_total, itens (lista de {descricao, qtd, valor})."
    )
    resp = bedrock.converse(
        modelId=MODEL_ID,
        messages=[{"role": "user", "content": [
            {"image": {"format": "jpeg", "source": {"bytes": img_bytes}}},
            {"text": prompt}
        ]}]
    )
    return json.loads(resp["output"]["message"]["content"][0]["text"])

def processar_documento(key: str) -> None:
    try:
        dados = extrair_com_visao(BUCKET_IN, key)
        out_key = key.replace(".jpg", ".json").replace(".pdf", ".json")
        s3.put_object(
            Bucket=BUCKET_OUT, Key=out_key,
            Body=json.dumps(dados, ensure_ascii=False).encode(),
            ContentType="application/json"
        )
        print(f"✅ {key} → {out_key}")
    except ClientError as e:
        print(f"❌ Erro S3/Bedrock em {key}: {e}")
    except (json.JSONDecodeError, KeyError) as e:
        print(f"⚠️  Parsing falhou em {key}: {e}")

def processar_bucket_em_batch(prefix: str = "faturas/") -> None:
    paginator = s3.get_paginator("list_objects_v2")
    for page in paginator.paginate(Bucket=BUCKET_IN, Prefix=prefix):
        for obj in page.get("Contents", []):
            if obj["Key"].endswith((".jpg", ".jpeg", ".pdf")):
                processar_documento(obj["Key"])

if __name__ == "__main__":
    processar_bucket_em_batch("faturas/2025/")

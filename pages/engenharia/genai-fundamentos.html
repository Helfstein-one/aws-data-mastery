01

Introdução Teórica: A Revolução Transformer

Como as máquinas aprenderam a entender contextos profundos e gerar textos como humanos.

A revolução da inteligência artificial generativa moderna não começou com o ChatGPT, mas sim em 2017 com a publicação do artigo "Attention Is All You Need" pelos pesquisadores do Google. Eles introduziram a arquitetura Transformer. Ao contrário das antigas Redes Neurais Recorrentes (RNNs) e LSTMs que liam o texto sequencialmente palavra por palavra e esqueciam o começo da frase ao chegar no final, os Transformers utilizam o mecanismo de Self-Attention (Auto-Atenção).

O Self-Attention permite que o modelo processe todos os tokens de um documento simultaneamente, avaliando matematicamente a relevância (o "peso") que cada palavra tem em relação às outras, capturando conexões e dependências de contexto de longas distâncias de maneira massivamente paralela. Por isso eles são tão bons em gerar código SQL ou Python: eles conseguem correlacionar a tabela definida na linha 10 com o JOIN que está acontecendo na linha 300.

Processamento
Tokens não são Palavras
LLMs não enxergam letras, palavras ou espaços. Eles processam fragmentos chamados Tokens (em média, 1 token = 4 caracteres em inglês, ou 0.75 de uma palavra). Em português e código fonte, a tokenização pode ser menos eficiente. O modelo Titan ou Claude enxerga tudo como um array de números inteiros (IDs de tokens).
Limites Físicos
A Janela de Contexto
A Context Window é a "memória RAM" do modelo. É a quantidade máxima de tokens que o modelo consegue analisar simultaneamente somando o Input (sua pergunta) + Output (a resposta dele). Modelos antigos tinham 4K tokens; hoje, o Claude 3.5 processa 200K tokens (equivalente a 500 páginas de um livro).
Representação
Embeddings Semânticos
Para que o LLM entenda que "Rei - Homem + Mulher = Rainha", as palavras são transformadas em Vetores (Embeddings) em um espaço n-dimensional (ex: 1536 dimensões). Termos com significados próximos ficam espacialmente próximos, permitindo cálculos de distância matemática (Cosseno).

Alucinação (Hallucination) e a Falácia da Verdade

É crucial como Engenheiro de Dados entender que um LLM não é um banco de dados de fatos, nem uma calculadora. Ele é um preditor probabilístico de tokens. Dado um contexto e uma pergunta, ele calcula matematicamente qual é o próximo token mais provável de aparecer.

Se você perguntar algo que não está na sua base de treinamento ou no prompt, ele não dirá "não sei". Ele usará a probabilidade para gerar uma resposta que pareça correta linguisticamente, mas que é factualmente falsa. Chamamos isso de Alucinação. Em arquiteturas de dados corporativas, mitigamos isso através do Grounding — ancorando o conhecimento do modelo a dados reais através de RAG (Retrieval-Augmented Generation), que veremos no próximo módulo.

02

A Batalha dos Foundation Models no Amazon Bedrock

Como escolher o LLM correto (Custo vs Qualidade) para o seu pipeline de dados.

Ao construir aplicações de dados com GenAI na AWS, utilizamos o Amazon Bedrock, um serviço serverless que disponibiliza LLMs de várias empresas de ponta através de uma única API unificada. Não existe "um modelo para dominar a todos"; o segredo de um bom Arquiteto de IA é o roteamento dinâmico (Model Routing) baseado no caso de uso, custo e velocidade.

Quando usar qual?

A Escolha do Claude 3.5

O Claude é atualmente o estado da arte para código e estrutura. Se o seu pipeline de dados precisa que o LLM leia um PDF de 50 páginas de balanço financeiro, extraia os valores de EBITDA e retorne estritamente em um JSON validado, o Claude 3.5 Sonnet (ou o rápido Claude 3.5 Haiku) são incomparáveis. Eles respeitam tags XML de forma quase religiosa, sofrendo de pouquíssima variação de output.

A Escolha do Llama 3.1

Llama brilha no volume. Se você tem 1 milhão de avaliações de clientes que precisam ser classificadas como (Positivo/Negativo/Neutro) para alimentar uma tabela do Amazon Athena, rodar isso no Claude custaria milhares de dólares. O Llama 3.1 (especialmente a versão 8B ou 70B) entrega ~90% da qualidade do Claude para esse caso específico, custando 20x menos. Llama é excelente para "tarefas braçais" de processamento de linguagem natural.

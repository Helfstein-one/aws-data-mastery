Amazon Q: Business & Developer

A suite de IA generativa nativa da AWS — assistente empresarial para funcionários (Q Business), copiloto de código para desenvolvedores (Q Developer), e análise de dados em linguagem natural para BI (Q no QuickSight).

01

Mapa da Suite Amazon Q

Três produtos distintos para três personas: empresa, desenvolvedor e analista.

Funcionários
Q Business
Assistente empresarial que conecta a fontes de dados corporativas (S3, SharePoint, Jira, Confluence, Salesforce) via conectores gerenciados. Responde perguntas com citações e respeita permissões do IAM Identity Center.
Desenvolvedores
Q Developer
Copiloto de código integrado ao VS Code, JetBrains e AWS Console. Sugestões inline, geração de testes, `/transform` para migração Java 8→17, `/review` para code review automático, scan de segurança (CodeWhisperer integrado).
Analistas
Q no QuickSight
Perguntas em linguagem natural sobre datasets do QuickSight — "qual região teve maior crescimento no Q3?" gera visualizações automaticamente. Também cria dashboards por prompt e explica insights em linguagem natural.
AMAZON Q — ECOSSISTEMA DE PRODUTOS
📌 Legenda — Suite Amazon Q:
  • Componentes: Q Business (assistente corporativo), Q Developer (copiloto de código), Q in QuickSight (BI em linguagem natural).
  • Integração: IAM Identity Center controla acesso ao Q Business; conectores gerenciados sincronizam fontes de dados corporativas.
  • Contexto: Produtos distintos com licenças separadas; Q Developer tem tier gratuito individual.

Amazon Q Business — Assistente Corporativo

Conectores, guardrails, plugin actions e controle de acesso por IAM Identity Center.

Componentes Principais

Conectores Nativos (40+)
  • 📁 Amazon S3, RDS, Aurora
  • 📘 Microsoft SharePoint, Teams, OneDrive
  • 🔧 Jira Cloud, Confluence Cloud
  • ☁️ Salesforce, ServiceNow
  • 📧 Gmail, Google Drive, Slack
  • 🗄️ MySQL, PostgreSQL (via JDBC)
Controles de Segurança
  • 🔐 IAM Identity Center — SSO obrigatório
  • 🛡️ Guardrails — Bloqueia tópicos proibidos
  • 🏷️ ACL per document — Respeita permissões da fonte
  • 📊 CloudTrail — Audit log de todas as queries
  • 🔍 Source attribution — Citação obrigatória

Plugin Actions — Q Age como Agente

Além de responder perguntas, o Q Business pode agir: criar tickets no Jira, abrir casos no ServiceNow, enviar e-mails — tudo via Plugin Actions configuradas com OAuth 2.0:

// Configuração de Plugin Action — Criação de Ticket no Jira
{
  "pluginType": "SERVICE_NOW",
  "authConfiguration": {
    "oAuth2ClientCredentialConfiguration": {
      "secretArn": "arn:aws:secretsmanager:us-east-1:123:secret:jira-oauth",
      "roleArn": "arn:aws:iam::123:role/QBusinessPluginRole"
    }
  },
  "customPluginConfiguration": {
    "description": "Criar ticket no Jira quando usuário reportar bug",
    "apiSchemaType": "OPEN_API_V3",
    "apiSchema": {
      "s3": {
        "bucket": "my-schemas",
        "key": "jira-openapi.yaml"
      }
    }
  }
}
03

Amazon Q Developer — Copiloto de Código

Sugestões inline, /transform, /review, scan de segurança e customização por codebase.

Sugestões
Inline Completion
Autocomplete contextual em tempo real. Suporta Python, Java, TypeScript, Go, Rust, SQL e mais 15 linguagens. Sugestões de bloco completo com Tab para aceitar.
Refatoração
/transform
Migração automática: Java 8/11 → Java 17/21, Maven configs, dependências. Analisa o projeto inteiro, cria um plano de migração e aplica as mudanças em lote. Salva dias de trabalho.
Qualidade
/review & Security Scan
Code review automático com sugestões de melhoria e detecção de vulnerabilidades (SQL Injection, hardcoded secrets, path traversal). Integra com CodeGuru Reviewer no backend.

Customização com /dev — Contexto do seu Codebase

No plano Pro, o Q Developer pode ser treinado no seu repositório (até 10 GiB) via Amazon Q Customization. As sugestões passam a usar convenções, padrões e nomes do seu próprio código:

# Sem customização — sugestão genérica:
def get_user(user_id):
    # Q sugere: return db.query(User).filter(User.id == user_id).first()

# Com customização no seu codebase (usando seu padrão Repository):
def get_user(user_id):
    # Q sugere: return UserRepository.find_by_id(user_id, include_deleted=False)
    # (seguindo o padrão que Q aprendeu do seu código)
💡 Tiers do Q Developer
Free: 50 sugestões de chat/mês + sugestões inline ilimitadas para uso individual. Pro (US$ 19/mês): ilimitado + customização, /transform, agent features, scan de segurança avançado + integração com AWS Console.

Q no Amazon QuickSight — BI em Linguagem Natural

Perguntas em português, criação de dashboards por prompt e explicação de insights.

O Q no QuickSight permite que analistas sem conhecimento de SQL ou ferramentas de BI criem visualizações através de perguntas em linguagem natural:

Exemplos de Perguntas
  • 💬 "Qual região teve maior receita no último trimestre?"
  • 💬 "Mostre tendência de churn por segmento nos últimos 12 meses"
  • 💬 "Compare custo de aquisição por canal de marketing"
  • 💬 "Quais produtos têm estoque abaixo do mínimo?"
  • 💬 "Crie um dashboard de vendas com mapa e top 10 clientes"
Capacidades
  • 📊 NL to Visual — Pergunta → gráfico automático
  • 🏗️ Dashboard creation — "Crie um dashboard de..." gera layout completo
  • 💡 Narrative Insights — Explica variações em linguagem natural
  • 🔍 Anomaly detection — Detecta e explica outliers automaticamente
  • 📐 Calculations — Cria métricas calculadas por prompt

Q Business vs Bedrock custom vs Q Developer — qual escolher?

✅ Regra de Decisão
Use Q Business quando o objetivo é permitir que funcionários não-técnicos consultem bases de conhecimento corporativas sem configurar RAG. Use Bedrock KB quando você precisa de controle total sobre chunking, prompts e integração em aplicações. Use Q Developer para acelerar produtividade de engenheiros — o custo paga-se em horas economizadas.

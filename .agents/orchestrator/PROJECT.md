# Project: Financial Knowledge Pages Expansion & Enhancement

## Architecture
HTML5 static pages in `/pages/financas/`, CSS styling via `style.css` & `style-a11y.css`, JavaScript sidebar functionality in `js/sidebar.js` and inline scripts. KaTeX for math rendering. SVG for inline architecture and flow diagrams.
